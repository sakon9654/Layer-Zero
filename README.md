# Novel B

พื้นที่ทำงานสำหรับวางแผน เขียน และแก้ไขนิยาย **โลกชั้นที่ศูนย์ (Layer Zero)** ด้วย Git โดยใช้ repository นี้เป็น Source of Truth

## เริ่มเขียน

1. อ่าน `canon/INDEX.md` เพื่อค้นหา Canon ที่เกี่ยวข้อง
2. อ่าน `story/arcs/arc-01/outline.md` สำหรับ Arc ปัจจุบัน
3. คัดลอก `templates/chapter.md` ไปไว้ใน `manuscript/` เมื่อเริ่มบทใหม่
4. ตรวจ `canon/timeline/master-timeline.md` และ `notes/continuity.md` ก่อนแก้เหตุการณ์สำคัญ
5. บันทึกข้อเท็จจริงใหม่เป็นข้อเสนอจนกว่าผู้เขียนจะอนุมัติเป็น Canon

## โครงสร้าง

```text
manuscript/   ต้นฉบับที่เรียงตามลำดับการอ่าน
canon/        ข้อเท็จจริงหลักและความลับสำหรับผู้เขียน
story/        โครงเรื่องและ Arc ที่กำลังพัฒนา
planning/     premise, outline และ timeline
characters/   ประวัติ เป้าหมาย และพัฒนาการของตัวละคร
world/        กฎของโลก สถานที่ และคำศัพท์เฉพาะ
research/     แหล่งค้นคว้าและข้อเท็จจริงอ้างอิง
notes/        ความต่อเนื่องและบันทึกการแก้ไข
templates/    แม่แบบสำหรับบท ฉาก และตัวละคร
assets/       ภาพ แผนที่ และไฟล์ประกอบ
sources/      สำเนาแหล่งข้อมูลและประวัติที่มา ไม่ใช่ Canon โดยอัตโนมัติ
```

> เมื่อข้อมูลซ้ำกัน ให้ยึดลำดับความสำคัญใน `AGENTS.md` และแจ้งผู้เขียนหากพบความขัดแย้ง

## รูปแบบชื่อไฟล์

- บท: `01-chapter-title.md`, `02-chapter-title.md`
- ตัวละคร: `firstname-lastname.md` หรือชื่อสั้นที่ไม่ซ้ำกัน
- ใช้อักษรตัวเล็กและขีดกลางแทนช่องว่างเพื่อให้ลิงก์คงที่

## แนวทาง Git

- หนึ่ง commit ต่อหนึ่งการเปลี่ยนแปลงที่อธิบายได้ เช่น `draft chapter 03`
- ใช้ branch สำหรับการแก้ใหญ่หรือทดลองเส้นเรื่องทางเลือก
- อย่าแก้ชื่อไฟล์บทและเนื้อหาจำนวนมากใน commit เดียวกัน

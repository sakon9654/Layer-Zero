# ARC 02 — ทะเบียนตัวละครสำคัญ

> อนุมัติให้ใช้เป็นข้อมูลความต่อเนื่องของตัวละครตามคำขอผู้เขียน โดย **ไม่เลื่อนสถานะต้นฉบับตอน 01–13 จาก draft เป็น approved (ตอน 14 อนุมัติแล้ว)** และไม่ถือว่าคำพูดบุคคลพิสูจน์กลไก Deviation; ข้อมูลที่ยังพิสูจน์ไม่ได้กำกับไว้ตรงรายการ

| ตัวละคร | ข้อมูล/บทบาทที่ใช้เขียนต่อ | สถานะล่าสุด ณ ตอน 14 และข้อห้าม |
|---|---|---|
| นนท์ / นนทกร วัฒนากุล | 24 ปี, Unfiltered ไม่ใช่ Resonant และไม่ใช้ O-203; ผู้ช่วยสังเกตการณ์ภายนอกของสำนักงาน ค่าตอบแทนตกลง 3,000 บาทต่อวัน; เขารู้ว่าการช่วยคดีมีการประเมินตนควบคู่ | ได้รับเงินตามวันที่ทำงานและส่งบางส่วนให้แม่ในตอน 10; ยอมช่วยคดีต่อภายใต้ขอบเขตใหม่และสิทธิ์หยุด; **ไม่ได้เป็นเจ้าหน้าที่**; สมุดส่วนตัวยังอยู่กับสำนักงานและขอคืนเล่มจริง; ชื่อปรากฏในหลักฐานว่าเป็นผู้ลงนามแทนทั้งที่ไม่ได้ลงชื่อ; ตอน 13 เห็นเงาที่สองในภาพที่คนอื่น/กล้องไม่เห็น และเห็นป้ายเปลี่ยนเป็นชื่อตน **ไม่แปลว่าเขาตกลงรับแทน** |
| ริน | เจ้าหน้าที่ประสานและกำกับคดี ให้ข้อมูลตามที่ตรวจได้และรักษาสิทธิ์ของคนเกี่ยวข้อง | ชื่อและลายเซ็นของเธอปรากฏบนหนังสือโรงพยาบาลฉบับหนึ่งทั้งที่เธอปฏิเสธว่าเซ็น; **คนละฉบับ** กับซองขาวของสำนักงาน; ไม่ถือการปรากฏลายเซ็นเป็นความยินยอม |
| อธิคม | ผู้กำกับ/ตัดสินใจปฏิบัติการ; ให้แยกการช่วยบุคคลออกจากการรับเอกสาร | หลังช่วยชายหลังประตูแล้ว สั่งคงควบคุมพื้นที่; เห็นข้อความบนซองถึงสำนักงานเรื่อง 02.43 และ “จำนวนผู้กลับออกมา”; บันทึกว่าเป็นความคล้ายคลึงกับ ARC01 แต่ยังไม่ยืนยันความเกี่ยวข้อง และยังไม่เรียกนนท์มารับรู้แฟ้มเก่า |
| พิม | เจ้าหน้าที่ Resonant ที่ผ่านขั้นตอนใช้ O-203 ใน ARC02; คนละคุณสมบัติกับนนท์ | เก็บหลักฐาน/คำให้การแยกจากข้อสรุป; ไม่อ้างว่าใช้ Object ทุกชิ้นได้ |
| เอก | ผู้ขับรถและดูแลความปลอดภัยใกล้นนท์ | พยานได้ยินเสียงเรียกชื่อจากโทรศัพท์นนท์; เห็นกระดาษในห้องขยับ; ไม่มีข้ออ้างว่าเห็นทุกสิ่งที่นนท์เห็น |
| กานต์ | ญาติผู้เสียชีวิตในกลุ่มหนังสือแจ้งตาย ปฏิเสธว่าไม่ได้ลงลายเซ็นตามเอกสาร; มีภาพบุคคลหน้าเหมือน | อยู่บ้าน ติดต่อได้ปลายตอน 13; ห้ามสรุปว่าเธอเซ็นจริงหรือภาพยืนยันตัวตน |
| วิทย์ | บุคลากรโรงพยาบาลที่ข้อมูลบัตรเข้าออก/ลายเซ็นขัดกับคำให้การ | อยู่ในการดูแลตามที่ตกลง; ไม่สรุปว่าเขาใช้บัตร ณ เวลาในระบบจริง |
| สมบัติ | ผู้ป่วยอายุ 62 ปีหลังผ่าตัด ยังมีชีวิตแม้พบหนังสือถึงญาติผู้เสียชีวิต และเอกสารระบุ 13.40 น. | ยังมีชีวิต ณ เวลา 13.40 น. และปลายตอน 13; บอกลูกชายเองว่าอยากให้ทราบเรื่องและพบกัน; **อย่าระบุว่าเสียชีวิตตามเอกสาร** |
| ธนิต | ลูกชายวัยผู้ใหญ่ของสมบัติ | เดินทางมาพบพ่อและอยู่กับพ่อ; ไม่ลงชื่อรับเอกสารไม่ทราบที่มา |
| ปรเมศวร์ อินทรรักษ์ (ผู้ระบุตน) | ชายอายุ 46 ตามแฟ้มโรงพยาบาล ถูกค้นหาเพราะไม่พบข้อมูลจำหน่าย/ใบรับรองตาย/รายการบุคคลปัจจุบัน; มีเสียงที่คล้ายใน O-108 และภาพชายเสื้อฟ้า แต่ช่วงแรกยังไม่ยืนยันว่าเป็นเขา | ตอน 13 ทีมช่วยชายมีชีวิตออกจากหลังประตูไม้ 19.30 น.; เขาระบุชื่อปรเมศวร์และพูดกับน้องสาวเวลา 22.08 น.; แพทย์ดูแลภาวะขาดน้ำ/อ่อนเพลีย รอยืนยันตัวตนด้วยหลักฐานอิสระ ไม่ตีตราเสียชีวิตหรือสรุปความต่อเนื่องย้อนหลังด้วยเสียงเพียงอย่างเดียว |
| น้องสาวปรเมศวร์ (ยังไม่ตั้งชื่อ) | เคยคิดว่าพี่ชายกลับบ้านเพราะได้ยินเสียงเรียกและพบเสื้อสีฟ้าพับบนเก้าอี้ แต่ไม่เคยเห็นตัวเขา ณ บ้าน | ยินยอมให้ตรวจเสื้อและกระดาษคิว 041; ร้องขอให้แจ้งพี่ว่าเธอรออยู่ และได้คุยกับชายที่ระบุว่าเป็นพี่ในตอน 13 |
| มาลี | เจ้าหน้าที่เวชระเบียนที่ช่วยตรวจประวัติห้องและบัตรคิว | อธิบายว่าบัตร 041 คล้ายบัตรงานขนส่งเอกสาร; ยังไม่มีข้อมูลยืนยันว่าเป็นผู้ทำรายการผิดปกติ |

**หมายเหตุ:** E-017 คุณนาย เป็น Entity ที่มี established canon เดิม; ประโยค “คราวนี้มาเร็วกว่าครั้งก่อน” ปรากฏใน ARC02 แต่ไม่มีการแลกเปลี่ยนราคาในฉากนั้น และห้ามให้ตัวละคร/แฟ้มสรุปเฉลยเหตุการณ์เวลาอื่นตาม hidden canon.

## หลังตอนที่ 14 — สถานะส่งต่อ

- **นนท์:** สิ้นสุดขอบเขตงานภาคสนามคดีนี้แล้ว แต่ยังไม่ได้เป็นเจ้าหน้าที่; ตรวจบัญชีเงินที่จ่ายแล้วและผลประเมินพร้อมแก้ถ้อยคำให้ตรงข้อสังเกต; ยังขอสมุดเล่มจริงคืน (สำนักงานรับเรื่องและให้บัญชีทรัพย์สิน); ตอนจบเอกขับรถพาเขากลับไปกินข้าวบ้านแม่.
- **ริน:** จัดทำรายงานเหตุโดยไม่ประกาศว่าความเสี่ยงหมดไป ให้ผู้ช่วยตรวจถ้อยคำในส่วนตนเองและประสานคำขอคืนทรัพย์สิน.
- **อธิคม:** ลงชื่อรับรองรายงานด้วยตนเอง; ให้คงควบคุมพื้นที่/วัตถุ; อาจขอความร่วมมือนนท์ในคดีอนาคตโดยต้องทำข้อตกลงใหม่ ไม่ใช่ข้อผูกมัดเดิม.
- **พิม:** ข้อมูลเปรียบเทียบ O-108/O-203 และรายงานการรับรู้ยังคงมีข้อจำกัด ไม่ยกระดับเสียงหรือข้อความเป็นคำเฉลย.
- **เอก:** ขับรถพานนท์ออกจากสำนักงาน ยังมีภารกิจขับรถอื่น.
- **สมบัติ/ธนิต:** สมบัติยังมีชีวิต ฟื้นตัวกับครอบครัว และต้องการให้รายงานบอกตรง ๆ ว่าเขายังไม่ตาย.
- **กานต์/วิทย์:** ยังติดต่อหรือดูแลได้ตามบันทึก ไม่มีการเฉลยว่าพวกเขาเป็นผู้เซ็น/ใช้บัตรผิดปกติจริง.
- **ชายที่ระบุตนว่าปรเมศวร์:** ยังอยู่ในการรักษา อาการดีขึ้น รอหลักฐานยืนยันตัวตนย้อนหลัง ไม่ใช่ผู้ตายที่พิสูจน์แล้ว.
- **น้องสาวปรเมศวร์:** ได้สนทนากับชายที่ระบุว่าเป็นพี่; ยังไม่เปิดชื่อ.
- **มาลี:** ยังคงเป็นแหล่งคำให้การด้านเวชระเบียน/ระบบเอกสาร ไม่ระบุว่าเกี่ยวข้องกับการก่อ Deviation.
- **แม่ของนนท์:** ส่งข้อความบอกว่าแกงจืดอยู่ในตู้เย็น นนท์ตอบว่ากำลังกลับ.

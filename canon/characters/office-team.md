# ตัวละครสำนักงาน — ริน อธิคม พิม และเอก

> แฟ้มอ้างอิงสำหรับผู้เขียน: บันทึกบทบาทและพฤติกรรมที่ปรากฏในต้นฉบับ ไม่สร้างประวัติ นามสกุล อายุ ตำแหน่งยศ หรือความสามารถใหม่จากการเดา. ต้นฉบับตอน 01–14 เป็น `approved` ทั้งหมดตามคำสั่งผู้เขียน.

## ริน

- **บทบาท:** ผู้ประสาน/กำกับการสืบสวนภาคสนามและดูแลข้อตกลงการเข้าร่วมของนนท์ ประสานทีมแพทย์ ฝ่ายเทคนิค ฝ่ายควบคุมและครอบครัวผู้เกี่ยวข้อง
- **นิสัยที่แสดงผ่านการกระทำ:** ใช้ภาษารายงานแม่นยำ ไม่สรุปเกินหลักฐาน ยอมแก้ข้อความให้ตรงกับสิ่งที่ผู้ให้ข้อมูลเห็นจริง; ตรงไปตรงมาเรื่องข้อจำกัด/ความเสี่ยง ไม่ใช้อำนาจบังคับให้นนท์เข้าทดสอบหรือเซ็น; มีอารมณ์ขันแห้งเป็นครั้งคราว
- **ช่วงคดีหนังสือแจ้งตาย:** ชื่อ/ลายเซ็นของเธอปรากฏในหนังสือโรงพยาบาลทั้งที่เธอปฏิเสธว่าไม่ได้เซ็น; หลังประตูไม้เธอกำกับการช่วยบุคคลโดยแยกจากการรับเอกสาร; จัดทำรายงานสรุปวันที่ 2 ต.ค. และให้เจ้าของคำให้การตรวจแก้ถ้อยคำ
- **ปลายตอน 14:** ปฏิบัติการหลักสิ้นสุด แต่เธอยังติดตามความเสี่ยงและคำขอคืนสมุดของนนท์; ไม่มีหลักฐานว่าเธอรู้คำเฉลยความลับของนนท์หรือความสัมพันธ์สองคดี

## อธิคม

- **บทบาท:** ผู้กำกับ/อนุมัติการปฏิบัติการและตรวจสอบรายงาน ทำงานกับฝ่ายต่าง ๆ และตรวจข้อมูลแฟ้มเก่าคดีร้านสะดวกซื้อ
- **วิธีทำงาน:** ถามว่าข้อสรุปมีหลักฐานใดรองรับ แยกการช่วยคนจากการควบคุมวัตถุ อนุมัติการเข้าพื้นที่หลังประเมินความเสี่ยง ไม่ถือข้อความในระบบเป็นความยินยอม
- **ช่วงคดีหนังสือแจ้งตาย:** อนุมัติช่วยผู้ขอความช่วยเหลือออกจากประตูโดยไม่ให้เซ็นรับเอกสาร; คงควบคุมพื้นที่/ซอง; สังเกตข้อความบนซองถึงสำนักงานเกี่ยวกับเวลา 02.43 และ “จำนวนผู้กลับออกมา” คล้ายคดีร้านสะดวกซื้อ
- **ปลายตอน 14:** ตรวจและลงชื่อในรายงานสำนักงานที่สร้างขึ้นตามปกติ; บันทึกเชื่อมแฟ้มเพื่อสืบสวน ไม่ยืนยันว่าคดีทั้งสองเป็นเหตุเดียวกัน ไม่เรียกนนท์มาตอบคำถามจากแฟ้มเก่า; ไม่ทราบคำเฉลยผู้กลับคนที่ห้า

## พิม

- **บทบาท:** เจ้าหน้าที่ฝ่ายวิจัย/ตรวจหลักฐาน และเป็น Resonant ที่ใช้งาน O-203 ภายใต้เงื่อนไขเฉพาะรายชิ้น
- **วิธีทำงาน:** เทียบภาพต้นฉบับ/สำเนา/กล้อง คำให้การกับ log แยกความเห็นคนอื่นจากนนท์ จดเวลาหรือสถานะตามที่ตรวจได้; มีอารมณ์ขันในการทำงานร่วมกับนนท์
- **ช่วงคดี:** ตรวจเสียงโทรศัพท์ที่กู้ได้และเทียบกับสิ่งที่ผู้ฟังได้ยิน; เปรียบเทียบภาพลายเซ็น; ติดตามบัญชีผู้รับจำลองและสถานะส่งมอบ; บันทึกเงาที่นนท์รายงานโดยไม่รับรองว่าเจ้าหน้าที่อื่นเห็น
- **ข้อจำกัด:** เป็น Resonant ไม่เท่ากับ Unfiltered; ไม่ได้ใช้ Object ทุกชิ้นหรือพิสูจน์เจตนาของ Entity ได้

## เอก

- **บทบาท:** ผู้ขับรถ/ดูแลความปลอดภัยและอยู่ใกล้นนท์ในช่วงปฏิบัติการ
- **นิสัย:** สุภาพ พูดสั้น มีมุกหน้าตายเกี่ยวกับรถและการขับรถ; ดูแลเรื่องอาหารและการเดินทางโดยไม่แสดงบทผู้รู้ทุกอย่าง
- **หลักฐานที่เป็นพยาน:** ได้ยินเสียงผู้ชายเรียกชื่อจากโทรศัพท์นนท์ ได้ยินและเห็นกระดาษเปล่าในห้องขยับ; ไม่ได้เห็นเงาที่สองผ่านกล้องตามที่นนท์รายงาน
- **ปลายตอน 14:** พานนท์ออกจากสำนักงานกลับบ้านหลังสิ้นสุดขอบเขตงานคดีนี้; ยังมีงานขับรถอื่น ไม่ได้ลาออกหรือย้ายทีมตามเนื้อเรื่อง

**เงื่อนไข:** ชื่อตัวละครในเอกสารนี้เป็นชื่อที่ใช้ในเรื่อง; ห้ามเพิ่มนามสกุล อายุ หรือตำแหน่งทางการโดยไม่มีข้อมูลในตอนหรือคำตัดสินผู้เขียน.


## แนวทางคำเรียกและระดับความอาวุโสในการเขียนต่อ (ผู้เขียนกำหนดหลังอนุมัติตอน 7)

> ข้อกำหนดนี้เป็น **แนวทางภาษาบทสนทนา** ตามบทบาทการทำงานและความใกล้ชิดที่ปรากฏในเรื่อง ไม่ใช่การแต่งตั้งยศ ตำแหน่งราชการ หรือกำหนดอายุ/ปีงานใหม่. หากภายหลังมีข้อมูลลำดับบังคับบัญชาหรืออายุอย่างเป็นทางการ ให้ปรับตามข้อมูลนั้น.

| ผู้พูด → ผู้ถูกเรียก | คำเรียกในฉากสนทนาปกติ | คำเรียก/วิธีพูดในภารกิจทางวิทยุหรือรายงาน |
|---|---|---|
| นนท์ → ริน | **คุณริน** / ผม–คุณ | คุณริน; หากจำเป็นต้องชี้บทบาท ใช้ “หัวหน้าทีมภาคสนาม” ในคำบรรยาย ไม่ใช่ยศใหม่ |
| นนท์ → พิม | **คุณพิม** / ผม–คุณ | คุณพิม หรือ “ฝ่ายวิจัย” เมื่อระบุหน่วยงาน |
| นนท์ → เอก | **คุณเอก** / ผม–คุณ | คุณเอก หรือ “ฐาน” เมื่อส่งวิทยุที่จุดฐาน |
| นนท์ → อธิคม | **คุณอธิคม** / ผม–คุณ | คุณอธิคม ไม่ตีสนิทและไม่ใช้ชื่อเปล่า |
| ริน/พิม/เอก → อธิคม | **หัวหน้า** หรือ **คุณอธิคม** ตามความเป็นทางการ / ฉัน–คุณ, ผม–คุณ | “หัวหน้า” เมื่อรายงานตรง; “อธิคม” ในคำบรรยาย ไม่ใช้คำว่า “ผอ.” จนกว่าจะยืนยันชื่อตำแหน่งทางการ |
| พิม ↔ ริน; เอก ↔ ริน; พิม ↔ เอก | เรียกชื่อเล่นได้เมื่อคุยกันในทีมที่คุ้นเคย; น้ำเสียงเคารพกันตามหน้าที่ | ใช้ “ริน”, “พิม”, “เอก” หรือชื่อจุดปฏิบัติการเมื่อเรียกวิทยุ; เมื่อสั่งงานให้ระบุหน้าที่ชัด ไม่ทำให้ดูว่าเป็นหัวหน้าระดับเดียวกันโดยอัตโนมัติ |
| มนัส/เจ้าหน้าที่เทคนิค → ริน | **คุณริน** หรือ **หัวหน้าทีม** ตามบริบท / ผม–คุณ | ตอบ “รับทราบครับ” เรียก “หัวหน้าทีม” เมื่อจำเป็นต้องชี้ผู้ควบคุมคำสั่ง; มนัสไม่เรียกรินแบบสนิทโดยยังไม่มีฉากรองรับ |
| ริน/พิม/เอก → นนท์ | **นนท์**; ใช้คำว่า “คุณนนท์” เมื่อเป็นพิธีการ/ต่อหน้าพลเรือนหรือเอกสาร | “นนท์” ในภารกิจเมื่อระบุผู้รับวิทยุโดยตรง; ยังเรียกเขาเป็น “ผู้ช่วยภายนอก” เมื่ออธิบายสถานะ ไม่เรียกเป็นเจ้าหน้าที่ |
| เจ้าหน้าที่สำนักงาน → ครอบครัวผู้หาย/พนักงานอาคาร | **คุณแพร**, **คุณภัทร**, **คุณสุเมธ**, **คุณจิรา** ฯลฯ เมื่อยังไม่สนิท | ชื่อเต็มเมื่อยืนยันตัวบุคคลและทำรายงาน; สุภาพแม้อยู่ในสถานการณ์กดดัน |

- **ลำดับหน้าที่ที่ยืนยันแล้ว:** อธิคมอนุมัติ/กำกับปฏิบัติการ; รินควบคุมทีมภาคสนาม; พิมรับผิดชอบหลักฐาน/วิจัย; เอกดูแลความปลอดภัยและฐาน; มนัสเป็นเจ้าหน้าที่เทคนิคในทีม; นนท์เป็นผู้ช่วยภายนอก. ห้ามอนุมานอาวุโสจากอายุที่ยังไม่ระบุ หรือเลื่อนตำแหน่งพิม/เอกเอง.
- บทบรรยายใช้ชื่อเล่นตามปกติ ไม่ต้องใส่ “คุณ” ทุกครั้ง; บทพูดใช้สรรพนามให้สม่ำเสมอกับผู้พูดและสถานการณ์. การเรียกวิทยุ “ฐาน”, “ทีมเข้า”, “หัวหน้าทีม” เป็น **ชื่อหน้าที่เฉพาะภารกิจ** ไม่ใช่ยศ.
- ตอน 1–7 ที่อนุมัติแล้วมีบางบรรทัดเรียกชื่อสั้นตามความคุ้นเคยของทีม; ไม่เปลี่ยนความสัมพันธ์เป็นพี่น้องหรืออายุห่างกันโดยไม่มีหลักฐาน. หากแก้บทพูดเก่าเพื่อมาตรฐาน ให้แก้เฉพาะคำเรียก ไม่แตะเหตุการณ์หรือข้อมูลหลักฐาน.

# ARC 02 — ตัวตนที่พบและยังไม่จัดประเภท

## เงาที่สองหลังประตู / “ผู้รับ” (ชื่อเรียกชั่วคราวเท่านั้น)

- **สถานะ:** แหล่งการรับรู้ผิดปกติที่รายงานโดยนนท์; **ยังไม่มี E-number และยังไม่ได้ยืนยันว่าเป็น Entity แยกจาก Phenomenon ของหนังสือ**. ไม่เท่ากับ E-017, E-003, ชายเสื้อเทา ARC01 หรือบุคคลใดโดยไม่มีหลักฐาน.
- **พื้นที่พบ:** หลังประตูไม้ภายในพื้นที่พักเอกสารก่อนส่งออกของโรงพยาบาล ระหว่างช่วยชายที่ระบุว่าตนคือปรเมศวร์ (ARC02 ตอน 12–13).
- **นนท์รายงานว่าเห็น:** เงารูปร่างสูงกว่าชายด้านหน้า อยู่ด้านหลัง/ชิดช่องเปิด ยกมือไปทางกล้อง; มีป้ายคล้ายป้ายเจ้าหน้าที่เปลี่ยนข้อความ “ผู้รับ” → “ผู้รับแทน” → “นนทกร วัฒนากุล” → “รอดำเนินการ”. เจ้าหน้าที่คนอื่นและภาพกล้อง **ไม่แสดงเงาที่สอง**; การอ่านป้ายเป็นคำให้การนนท์.
- **สิ่งที่ตรวจได้แยกต่างหาก:** มีเสียงที่สองสุภาพจากหลังประตู กล่าว “ไม่พบข้อมูลบุคคลที่ขอรับการช่วยเหลือ”, “กรุณาระบุผู้รับแทน”, “รายการถูกส่งมอบแล้ว” ฯลฯ; คำกล่าวไม่ตรงกับสิ่งที่ทีมเห็น/การรับกระดาษที่ไม่มีผู้รับ. **ยังไม่พิสูจน์ว่าเสียงมาจากเงาที่นนท์เห็น**.
- **การตอบสนอง/ผลการปฏิบัติการ:** ทีมไม่รับหน้าที่ผู้รับแทน ไม่ลงชื่อในเอกสารผิดปกติ ช่วยคนผ่านประตูด้วยอุปกรณ์เคลื่อนย้ายโดยไม่พาซองออก; หลังช่วยได้ ระบบสำนักงานขึ้น “ไม่สามารถดำเนินการส่งมอบได้ / ผู้รับแทนไม่อยู่ในพื้นที่”; เป็นความสัมพันธ์ที่สังเกตครั้งนี้ ไม่ใช่กฎสากลหรือยุติภัยถาวร.
- **สิ่งไม่ทราบ:** ตัวตน จำนวนที่แท้จริง จุดกำเนิด เจตนา ความเกี่ยวข้องกับ O-108/โทรศัพท์ ผู้ส่ง ผู้รับเดิม E-017 และ ARC01.

## E-017 “คุณนาย” (existing canon)

- ใน ARC02 ตอน 07 ทักนนท์ว่า **“คราวนี้มาเร็วกว่าครั้งก่อน”**; เจ้าหน้าที่บันทึกคำกล่าวและไม่พบข้อมูลการพบกันเดิมในช่วงที่ค้นได้. นนท์ไม่ได้ตกลงแลกข้อมูล/ชำระราคาในการพบครั้งนี้.
- คำกล่าว **ไม่ใช่หลักฐานว่านนท์ลืมเหตุการณ์อดีต**; อย่าเปิดเผยความจริงระดับ author-only เกี่ยวกับเวลา/การพบกันก่อนถึงจังหวะผู้เขียนกำหนด.

## E-003 “ผู้เช่า”

- Existing World Canon แต่ **ไม่ได้ยืนยันว่ามีบทบาทในคดีหนังสือแจ้งตาย**.

# AUTHOR-ONLY CANON — RESONANCE และ THE VEIL

> ห้ามให้เจ้าหน้าที่ทั่วไป ตัวละคร หรือผู้อ่านทราบข้อมูลนี้ก่อนจุดเปิดเผยที่ผู้เขียนอนุมัติ

## 9. ความสัมพันธ์กับ THE VEIL

ข้อมูลระดับ AUTHOR-ONLY CANON:

Resonance และ Unfiltered Perception เกี่ยวข้องกับความสัมพันธ์ระหว่างมนุษย์กับ Layer Zero แต่ส่งผลคนละด้าน

Unfiltered Perception เกี่ยวข้องกับข้อจำกัดในการรับรู้ข้อมูล

Resonance เกี่ยวข้องกับความสามารถในการเกิดปฏิสัมพันธ์กับ Deviation

มนุษย์ทั่วไปอาจไม่สามารถมองเห็น Object บางชิ้นเพราะ The Veil

Unfiltered อาจมองเห็น Object ดังกล่าว แต่ไม่สามารถกระตุ้นการทำงานของมัน

Resonant อาจสามารถกระตุ้นการทำงานของ Object ได้ แต่ไม่จำเป็นต้องรับรู้สิ่งที่ The Veil ปิดบัง

สำนักงานยังไม่เข้าใจกลไกทั้งหมดของ Resonance และยังไม่สามารถยืนยันความสัมพันธ์ระหว่าง Resonance กับ The Veil ได้อย่างสมบูรณ์

ห้ามให้เจ้าหน้าที่ทั่วไปทราบความจริงระดับผู้เขียนนี้ตั้งแต่ต้นเรื่อง

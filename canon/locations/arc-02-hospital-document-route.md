# ARC 02 — สถานที่สำคัญ

## โรงพยาบาลที่เกิดคดีหนังสือแจ้งตาย (ชื่อทางการยังไม่ตั้ง)

- โรงพยาบาลในกรุงเทพฯ มีระบบเวชระเบียน ห้องผู้ป่วย ทางบริการ ระบบกล้อง และห้องรับส่งเอกสาร; **ยังไม่มีชื่อโรงพยาบาลที่ผู้เขียนยืนยัน** ไม่ตั้งชื่อขึ้นเองย้อนหลัง.
- **กล่องเอกสารชุด 47 / บริเวณห้องเวชระเบียน:** พบหนังสือกลุ่มเสียชีวิตและฉบับที่เกี่ยวข้องกับสมบัติซึ่งยังมีชีวิต; เอกสาร/ข้อมูลประตูเคยปรากฏในสภาพไม่ตรงกับการตรวจครั้งก่อน.
- **ทางบริการ:** ภาพกล้อง S-01 ถึง S-04; วันที่ 23 ก.ย. 16.13 ตามเวลาไฟล์ พบภาพชายเสื้อฟ้าถือซองขาว; นาฬิกาในภาพสองตำแหน่งแสดง 17.41 เฉพาะช่วงดังกล่าว ไม่ยืนยันว่าคลาดเคลื่อนเพราะอะไร; ภาพทางบริการและ log บัตรเวลา 16.12 ไม่ยืนยันเส้นทางคนเดียวกันโดยลำพัง.
- **ห้องรับส่งเอกสาร:** มีโต๊ะ ตู้แฟ้ม เครื่องพิมพ์ ถาด “รับเข้า / ส่งออก / ตีกลับ”; รายการ 041 ในสมุดและซองน้ำตาลในถาดตีกลับ; ตามข้อมูลโรงพยาบาลไม่มีคนประจำตั้งแต่ 23 ก.ย. ไม่สรุปว่าไม่เคยมีคนเข้าใช้.
- **พื้นที่พักเอกสารก่อนส่งออก:** อยู่หลังประตูด้านหลังห้องรับส่งเอกสาร; ปรากฏในผังเก่าแต่ไม่อยู่ในผังใช้ปัจจุบัน; ประตูชั้นแรกมีระบบบัตร/log ใช้ชื่อปรเมศวร์ 23 ก.ย. 16.12 แต่หมายเลขบัตรที่ระบบทางบริการแสดงเกี่ยวข้องกับฝ่ายรับเอกสารสำนักงาน; หลังเปิดประตูชั้นแรกมีทางเดิน เก้าอี้ ถุงใสพร้อมซองขาว และประตูไม้บานใน. ตอน 13 ช่วยชายหนึ่งคนผ่านประตูไม้เวลา 19.30 น.; ไม่พาซองหรือกระดาษออกด้วย; ทีมถอนกำลัง ปิดประตูชั้นแรก คงการควบคุมพื้นที่และหยุดใช้ห้องรับส่งเอกสารเดิมจนประเมินซ้ำ.
- **ห้องผู้ป่วยสมบัติ:** เขายังมีชีวิต พูดกับลูกชายธนิต/ภรรยา; ทีมยืนยันสถานะด้วยคน/แพทย์แยกจากข้อความบนหนังสือ.

## สำนักงาน / พื้นที่ควบคุมหลักฐาน

- มีห้องประชุม ห้องตรวจภาพ/ห้องสังเกตการณ์ ห้องใช้ O-108 ภายใต้ protocol ห้องเก็บหลักฐานที่แยกซองขาวถึงสำนักงานกับสมุดนนท์และกระดาษจากห้องพัก; ไม่มีการยืนยันว่าซองที่พื้นที่โรงพยาบาลเป็นใบเดียวกับที่เก็บสำนักงาน.
- ระบบรับเอกสารของสำนักงานบันทึกชื่อผู้ลงนามแทนที่เจ้าตัวไม่ได้ลงชื่อ; สำนักงานใช้แบบฟอร์ม **“บันทึกการพบและควบคุมวัตถุ”** แยกการเก็บหลักฐานจากความยินยอมในเอกสารผิดปกติ.

## ห้องพักชั่วคราวของนนท์

- ที่พักภายใต้การดูแล/ประสานความปลอดภัยของสำนักงาน เอกอยู่ใกล้; พบข้อความในโทรศัพท์และกระดาษเปล่าที่มีเสียงและขยับเอง; ไม่ตีความว่าทุกห้องพักถูกแปลงเป็น Location Deviation อิสระ.

## ตอน 14 / สถานะหลังจบปฏิบัติการ

- โรงพยาบาลหยุดใช้เส้นทางห้องรับส่งเอกสารเดิมในปฏิบัติการปกติ; พื้นที่และซองที่พบยังถูกควบคุม ไม่ใช่รื้อ/ทำลายหรือปลดการควบคุม.
- ฉากท้ายวันที่ 2 ต.ค. 23.41 น. ห้องรับส่งเอกสารไม่มีคน ประตูหลังปิด ซองสีน้ำตาล 041 อยู่ถาดตีกลับ และมีเสียงสุภาพจากหลังประตูไม้ในพื้นที่พักเอกสารขอให้ตรวจรายการค้างส่ง; ไม่ถือว่าพื้นที่ปลอดความผิดปกติ.

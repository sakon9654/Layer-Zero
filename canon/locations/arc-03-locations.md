# ARC 03 — Locations

## อาคารสำนักงานเอกชน / อาคาร 17 ชั้น
- เอกสารก่อสร้าง/การใช้งานที่ตรวจได้รองรับ **17 ชั้น**.
- หลายบุคคล/ระบบอ้าง “ชั้น 18”; ทีมพบพื้นที่ภายในไม่สอดคล้องผัง แต่การเข้าถึงและหมายเลขชั้นไม่คงที่.
- ห้ามเขียนว่า “อาคารมีชั้น 18 ทางกายภาพ” เป็นข้อเท็จจริง.
- หลัง 3 พ.ย. ยุติปฏิบัติการหลัก แต่คงเฝ้าระวัง.
- 3 พ.ย. 22.04 Access Control สร้าง **ACCESS EVENT / LOCATION: — / RESULT: CLOSED** โดยไม่จับคู่เหตุทางกายภาพ; บันทึกเป็นเหตุไม่ทราบสาเหตุ.

## “ฝ่ายประสานงานภายใน”
- ปรากฏเป็นฝ่าย/พื้นที่/ระบบงานที่สัมพันธ์กับ anomaly.
- ระบบอ้างประวัติย้อนหลังประมาณ 11 ปี แต่แหล่งกำเนิดและโครงสร้างบริหารยังไม่ยืนยัน.
- ห้ามนิยามเป็น Entity หรือองค์กรอิสระที่พิสูจน์แล้ว.

## บ้านเก่าครอบครัววัฒนากุล — ลาดพร้าว
- ขายหลังพ่อนนท์เสียชีวิต.
- เชื่อมเหตุปี 2558: นนท์วัย 14, จิรา, บัตร 24 และคำให้การเรื่องประตูที่นนท์เห็นแต่จิราไม่เห็น.
- 1 พ.ย. ทีมตรวจพบพื้นที่สะอาดรูปสี่เหลี่ยมขนาดโต๊ะที่เกิด/หาย และภาพ/เงาสะท้อนที่ยังอธิบายไม่ได้.
- มีหลักฐานสนับสนุนว่าเป็น “จุดก่อนรับรายการ” ของจิรา แต่ไม่ใช่กฎทั่วไปที่พิสูจน์แล้ว.

## ที่พักชั่วคราวของจิรา
- หลัง Return Protocol จิราเลือกพักที่สำนักงานประสาน; ไม่ใช่บ้านนนท์หรือบ้านเก่า.

## จุดประตู 16 พ.ย. 2569
- ผนังอาคารพาณิชย์ระหว่างร้านขายยากับร้านถ่ายเอกสาร ระหว่างทางจากสำนักงานไปสถานี.
- 17.36–17.42 นนท์เห็นประตูสีขาว; กล้อง/บุคคลอื่น/เจ้าของอาคารไม่ยืนยัน.
- นนท์ไม่เข้าใกล้/ไม่เปิด; ทีมตรวจภายหลังไม่พบร่องทางกายภาพ.
- ยังไม่เชื่อมกับประตูบ้านเก่า ร้านสะดวกซื้อ หรือพื้นที่อาคาร ARC 03.

# ARC 02 — วัตถุและหลักฐานสำคัญ

> รายการนี้บันทึก **หลักฐานที่ปรากฏจริงในร่างและสถานะที่ผู้เขียนขอให้คงเป็น canon continuity** ไม่ใช่คำยืนยันว่าทุกชิ้นเป็น Object อิสระ ห้ามออกเลข O ใหม่โดยพลการ

## Object ที่มีรหัสอยู่ก่อน

- **O-108 “เทปผู้เสียชีวิต”** — Existing World Canon: เครื่องเล่นเทปบันทึกเสียงช่วงก่อนการเสียชีวิตของบุคคลในบริเวณนั้น; ไม่ทราบว่าเสียงมาจากอดีตจริง ความทรงจำสถานที่ หรือแหล่งอื่น; มีอย่างน้อยหนึ่งเหตุการณ์ที่สิ่งในบันทึกรู้ว่ามีผู้ฟัง. ใน ARC02 ตอน 09 ได้เสียงคล้ายปรเมศวร์กับเสียงแทรกที่นนท์รายงานว่า “ไม่อยู่แล้ว”; **ห้ามยืนยันจากเสียงว่าเขาตายจริง/ทำนายอนาคต**. เสียงโทรศัพท์ในตอน 09–10 ยังไม่พิสูจน์ว่า O-108 ส่งต่อไปมือถือด้วยกลไกใด.
- **O-203 “กระดาษคำถาม”** — รายละเอียดกลไกยังอยู่ใน ARC01/ARC02 dossier ตามสถานะเอกสารต้นทาง; พิมเป็น Resonant ที่ใช้งานตามขั้นตอนใน ARC02; นนท์มองเห็นต่างได้แต่ **ใช้ O-203 เองไม่ได้**. ไม่ใช่เครื่องบังคับคำตอบจริง.

## วัตถุหลักฐาน ARC02 — แยกชิ้นห้ามรวมตามหน้าตา

| หลักฐาน | สถานะ ณ ตอน 13 | ข้อควรระวัง |
|---|---|---|
| ซองสีขาวถึงสำนักงาน (ปรากฏตอน 07) | อยู่พื้นที่ควบคุมสำนักงาน; ระบบเคยขึ้น “รับทราบแล้ว / ผู้ลงนามแทน: นนทกร วัฒนากุล”; ตอน 13 เปลี่ยนเป็น “ไม่สามารถดำเนินการส่งมอบได้ / ผู้รับแทนไม่อยู่ในพื้นที่”; ต่อมาหลังซองปรากฏ “หนังสือฉบับสุดท้าย”, “02.43”, “ให้ตรวจสอบจำนวนผู้กลับออกมา” | ไม่มีหลักฐานนนท์เซ็น; ไม่ยืนยันว่าคือซองขาวในถุงจากพื้นที่โรงพยาบาล |
| ซองสีขาวในถุงพลาสติก | พบเก้าอี้ทางเดินหลังประตูชั้นแรกของพื้นที่พักเอกสาร; ปรากฏ “ถึง: สำนักงาน / ผู้ส่ง: ไม่สามารถยืนยันตัวตน”; ยังอยู่ในเขตควบคุมเดิมตอน 13 | **คนละตำแหน่ง** กับซองขาวที่สำนักงาน ไม่สรุปเป็นต้นฉบับเดียวกัน |
| ซองสีน้ำตาลหมายเลข 041 | อยู่ถาด “ตีกลับ” ในห้องรับส่งเอกสาร ข้อความ “ส่งกลับผู้ส่ง”, ไม่มีชื่อผู้ส่ง; ยังไม่เคลื่อนย้ายในตอน 13 | หมายเลขตรงกับบัตรคิวและสมุด ไม่พิสูจน์กลไกทั้งหมด |
| ซองถึงญาติผู้เสียชีวิตชื่อสมบัติ | พบขณะสมบัติยังมีชีวิต; ปรากฏ “กรณีผู้รับยังมีชีวิต / โปรดระบุผู้รับแทน” | ไม่เท่ากับคำทำนายตายหรือความยินยอมญาติ |
| หนังสือโรงพยาบาลมีลายเซ็นริน | รินยืนยันว่าไม่ได้เซ็น; นนท์เห็นช่องว่างในภาพจากกล้องถ่ายต้นฉบับ ขณะที่คนอื่นเห็นชื่อ/ลายเซ็น | **ไม่ใช่ซองสีขาวถึงสำนักงาน** และห้ามเรียกว่าลายเซ็นจริง |
| หนังสือใหม่ถึงสมบัติ เวลา 13.40 น. | ไม่มีชื่อผู้เสียชีวิต; หลังเวลา 13.40 น. สมบัติยังมีชีวิต และเอกสารปรากฏข้อความดำเนินการไม่ได้/ช่องผู้รับแทนว่าง | 13.40 ไม่พิสูจน์เวลาเสียชีวิต |
| สมุดส่วนตัวของนนท์ | สำนักงานครอบครองและประเมินการคืน; เคยมีข้อความ/ลายเซ็นผิดปกติ; เศษกระดาษลงท้าย “…จึงจัดส่งถึงสำนักงาน” | เป็นทรัพย์สินนนท์ก่อนเกิดเหตุ; เจ้าตัวยังไม่ได้เล่มจริงคืน |
| กระดาษ A4 เปล่าห้องนนท์ | มีเสียงและขยับให้เอก/กล้องเห็น; เก็บแยกจากสมุด | ไม่ยืนยันว่ามันเป็น Object แยกประเภท |
| โทรศัพท์ต้นฉบับ/โทรศัพท์สำรองนนท์ | โทรศัพท์เดิมถูกเก็บตรวจหลังมีเสียงเหมือน O-108; เครื่องสำรองมีข้อความเรื่องผู้รับเดิม/ผู้รับแทน | ไม่มีหลักฐานผู้ส่งข้อความ ไม่สรุปว่าเสียงมาจาก O-108 โดยตรง |
| บัตรคิว 041 ในเสื้อฟ้าบ้านปรเมศวร์ | ข้อความ “ถ้าไม่พบชื่อผม อย่าลงชื่อแทน”; น้องสาวให้ตรวจ | ผู้เขียนลายมือยังไม่ยืนยัน |
| สมุดรับส่งเอกสารสีดำ | เลขรับ 041 วันที่ 23 ก.ย. 16.12 ช่องผู้ส่ง/ผู้รับว่าง; 040 มีต้นทางและปลายทางตามปกติ | สถานะรายการ ≠ สถานะบุคคล |
| กระดาษค้างในเครื่องพิมพ์ห้องรับส่ง | “ไม่สามารถนำส่งถึงผู้รับเดิม / ไม่สามารถส่งกลับผู้ส่ง / ให้ดำเนินการส่งถึงหน่วยงานที่รับผิดชอบ” | หน่วยงานปลายทางยังว่าง ไม่ยืนยันผู้ส่ง |
| กระดาษที่หลุดมือชายหลังประตูไม้ | หล่นอยู่ด้านในตอนช่วยออกมา; มีเสียงกล่าวว่า “รายการถูกส่งมอบแล้ว” แต่เจ้าหน้าที่ไม่มีใครรับ | ยังไม่ถือเป็นการส่งมอบจริงหรือหลักฐานยินยอม |

**กฎความรู้:** ข้อความบนหลักฐาน, log ระบบ, ภาพ, เสียง, คำให้การ และความจริงของบุคคลต้องแยกชั้นกันทุกครั้ง.

## ตอน 14 / สถานะส่งต่อ

- รายงานปิดปฏิบัติการหลัก ณ 2 ต.ค. ระบุหลักฐานอยู่ในการควบคุม ไม่ยืนยันว่าความผิดปกติสิ้นสุด.
- สมุดปกสีน้ำเงินของนนท์ยังอยู่สำนักงาน มีบัญชีทรัพย์สินและคำขอคืนเล่มจริง; การเก็บหลักฐานไม่โอนกรรมสิทธิ์.
- ซองขาวถึงสำนักงาน / ซองขาวในถุง / ซองน้ำตาล 041 แยกหลักฐานเสมอ. การไม่ลงชื่อและช่วยบุคคลออกมา **สัมพันธ์** กับสถานะส่งมอบไม่สำเร็จ แต่ไม่ใช่กฎยืนยันว่าป้องกันได้ทุกกรณี.

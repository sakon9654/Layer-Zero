# ARC 03 — Objects / Evidence

## บัตรสีขาวหมายเลข 24
- ปรากฏพร้อมบุคคลที่ระบุตนเป็นจิรา 1 พ.ย. 2569.
- พลาสติกสีขาว หมายเลข 24 ไม่มีแถบ/ชิปที่มองเห็น.
- ข้อความ: **“ผู้ถือบัตรไม่มีหน้าที่รับช่วงโดยอัตโนมัติ”**.
- ร่องรอยที่ถูกลบ: **“คืนแล้ว — 14/08/58”** และชื่อ **“นพดล วัฒนากุล”**.
- การตรวจชั้นหมึกสนับสนุนเพียงว่าชื่อพ่อกับ “คืนแล้ว” อยู่ต่างช่วงการเขียน; ไม่ยืนยันผู้เขียน/ผู้ถือ.
- หลังชื่อพ่อมี **23.41** โดยไม่ทราบวันที่หรือเวลาที่เขียน.
- รอยกดอ่านได้ **“ถ้านนท์เห็นประตู อย่าให้เขาเป็นคนเปิด”**; ไม่มีวันที่/ผู้เขียน/หลักฐานว่าเป็นจิรา.
- ห้ามใช้บัตรพิสูจน์ว่าพ่อนนท์ก่อเหตุ เปิดประตู เข้าอาคาร หรือทำให้จิราหาย.

## 23.41 / “ผู้เปิดประตู”
- 23.41 ปรากฏทั้งบนบัตร 24 และข้อมูลเก่าคดีร้านสะดวกซื้อ.
- ตามตอน 16 ที่ approved metadata ที่กู้ได้แสดง **“เริ่มตรวจจำนวน”**, **“รายการที่ไม่ยืนยัน: ผู้เปิดประตู”**, **“สถานะก่อนเริ่มตรวจ: ไม่ครบ”**.
- version ที่กู้ได้ระบุ created 18 ก.ย. 2569 23.41; “ผู้เปิดประตู” อยู่ใน version แรก ส่วนตัวเลขเข้า/ออกเพิ่มภายหลัง.
- field เพิ่มเติม: **“สถานะรายการ: รอเหตุ”**.
- ทั้งหมดเป็นข้อมูลแฟ้ม/metadata ไม่ใช่ข้อพิสูจน์ว่าระบบทำนายอนาคต.
- **ยังไม่มีหลักฐานเชื่อม “ผู้เปิดประตู” กับนนทกร วัฒนากุล**.
- เวลาเดียวกันไม่พิสูจน์ว่าคดีร้านสะดวกซื้อ บัตร 24 และคดีอาคารเป็นกลไกเดียวกัน.

## ฝ่ายประสานงานภายใน
- ระบบหลายชุดแสดงฝ่ายนี้ย้อนหลังประมาณ 11 ปี พร้อมรายชื่อ/สถานะงาน.
- สถานะงาน/บุคคลเคยขัดหลักฐานทางกายภาพ.
- คำอย่าง “ผู้รับช่วง”, “รอผู้ยืนยัน”, “ไม่ยอมส่งมอบ”, “คืนรายการ”, “สิทธิ์ออก” เป็นศัพท์ของระบบ ไม่ใช่กฎจักรวาลที่พิสูจน์แล้ว.

## รายงานปิดปฏิบัติการ
- **รายงานสรุปเหตุผิดปกติ — อาคารสำนักงานเอกชน**
- หลัง 3 พ.ย.: **ยุติปฏิบัติการหลัก / คงเฝ้าระวัง / ติดตามผู้ได้รับผลกระทบ / คงสืบสวนแหล่งกำเนิดข้อมูลและกลไก**.
- ไม่สรุปว่า “พบชั้น 18”; บันทึกเพียงข้อมูลหลายช่องทางสัมพันธ์กับชั้น 18 และพื้นที่ภายในไม่สอดคล้องผัง.
- สาเหตุยัง **ไม่สามารถระบุได้**.

## หลักการหลักฐาน
“ระบบระบุ” ≠ เกิดทางกายภาพ; “ญาติยืนยัน” ≠ ปิด Return Protocol; “ชื่อ/เวลาเดียวกัน” ≠ กลไกเดียวกัน; “ไม่ตรวจพบ” ≠ “ไม่มี”; “ออกจากพื้นที่” ≠ คืนชีวิตเดิมสมบูรณ์.

# WORLD SETTING: โลกชั้นที่ศูนย์

## 1. แนวทางของเรื่อง

เรื่องเกิดขึ้นในโลกปัจจุบันที่ภายนอกแทบไม่ต่างจากโลกจริง มนุษย์มีเทคโนโลยี สังคม การเมือง อินเทอร์เน็ต วิทยาศาสตร์ และประวัติศาสตร์ใกล้เคียงโลกจริง

สิ่งที่ประชาชนทั่วไปไม่รู้คือ โลกมีปรากฏการณ์ วัตถุ สถานที่ และตัวตนที่ไม่สามารถอธิบายด้วยกฎธรรมชาติที่มนุษย์รู้จัก

เหตุการณ์เหล่านี้เกิดขึ้นทั่วโลกมาตลอดประวัติศาสตร์

ตำนานเมือง เรื่องผี ความเชื่อพื้นบ้าน เหตุการณ์บุคคลสูญหาย ข่าวประหลาด ภาพถ่ายลึกลับ สัญญาณวิทยุไม่ทราบที่มา และทฤษฎีสมคบคิดบางประเภท อาจมีต้นกำเนิดจากการที่มนุษย์ธรรมดาเคยสัมผัส “เศษเสี้ยว” ของปรากฏการณ์เหล่านี้

อย่างไรก็ตาม ไม่ควรถือว่าตำนานหรือทฤษฎีสมคบคิดในโลกจริงเป็นความจริงโดยตรง

นิยายสามารถนำเหตุการณ์หรือแนวคิดจากโลกจริงมาเป็นจุดตั้งต้น ก่อนสร้างคำอธิบายเหนือธรรมชาติของจักรวาลเรื่องขึ้นใหม่

โทนหลักของเรื่องคือ

- Mystery / Investigation
- Supernatural
- Cosmic Horror
- Psychological Horror
- Bureaucratic Horror
- Action / Survival

หัวใจของเรื่องคือ “การสืบสวนสิ่งที่มนุษย์อาจไม่มีความสามารถเพียงพอที่จะเข้าใจอย่างสมบูรณ์”

# 2. ธรรมชาติของความจริง

มนุษย์เข้าใจว่าจักรวาลดำเนินไปภายใต้กฎธรรมชาติชุดหนึ่ง

แต่ความเข้าใจดังกล่าวไม่สมบูรณ์

สิ่งที่มนุษย์เรียกว่า “ความจริง” เป็นเพียงสภาวะหนึ่งของความเป็นจริงที่มีเสถียรภาพสูงพอให้มนุษย์ดำรงชีวิตและพัฒนาวิทยาศาสตร์ขึ้นมาได้

สำนักงานเรียกสภาวะนี้อย่างไม่เป็นทางการว่า

**Layer Zero — ชั้นที่ศูนย์**

Layer Zero ไม่จำเป็นต้องหมายถึงมิติทางกายภาพ

มันอาจหมายถึงชุดของกฎ ความสัมพันธ์ เหตุและผล การรับรู้ เวลา พื้นที่ และข้อมูลที่มนุษย์ถือว่าเป็นเรื่องปกติ

นอกเหนือจาก Layer Zero มีสิ่งที่สำนักงานเรียกรวม ๆ ว่า

**The Deep — เบื้องลึก**

ไม่มีทฤษฎีใดได้รับการยืนยันว่า The Deep คืออะไร

สมมติฐานประกอบด้วย:

- มิติอื่น
- ชั้นความจริงอื่น
- จักรวาลที่ซ้อนทับกับจักรวาลมนุษย์
- สภาวะของข้อมูลที่อยู่เหนือกฎฟิสิกส์
- จิตสำนึกระดับจักรวาล
- ความจริงดั้งเดิมที่ Layer Zero แยกตัวออกมา
- สิ่งที่ไม่สามารถอธิบายด้วยแนวคิดเรื่อง “สถานที่” หรือ “มิติ” ได้เลย

คำว่า The Deep จึงเป็นเพียงศัพท์ที่มนุษย์สร้างขึ้นเพื่อใช้เรียกสิ่งที่ยังไม่เข้าใจ

# 3. Deviation

**Deviation — ความคลาดเคลื่อน**

เป็นคำกลางที่สำนักงานใช้เรียกเหตุการณ์หรือสิ่งใดก็ตามที่แสดงคุณสมบัติขัดแย้งกับความเข้าใจเรื่องความจริงของมนุษย์

Deviation ไม่ใช่เวทมนตร์

โลกนี้ไม่มีระบบมานา เวทมนตร์ ธาตุ หรือกฎพลังที่มนุษย์เข้าใจอย่างสมบูรณ์

Deviation แต่ละชนิดอาจมีกฎของมันเอง

ตัวอย่างเช่น:

พื้นที่ภายในห้องอาจใหญ่กว่าขนาดภายนอก

บุคคลอาจถูกลบออกจากความทรงจำของผู้พบเห็น

วัตถุอาจตอบสนองต่อคำพูดบางคำ

เสียงอาจเดินทางย้อนเวลา

ภาพถ่ายอาจมีบุคคลที่ไม่เคยอยู่ในสถานที่นั้น

ประตูอาจนำไปยังสถานที่ต่างกันขึ้นอยู่กับว่าใครเป็นคนเปิด

ศพอาจให้ข้อมูลเกี่ยวกับเหตุการณ์ที่ยังไม่เกิดขึ้น

สิ่งสำคัญคือ Deviation ส่วนใหญ่ไม่ได้ “ไร้กฎ”

มันมักมีกฎบางอย่าง

ปัญหาคือมนุษย์ยังไม่รู้กฎเหล่านั้นทั้งหมด

การสืบสวนจึงเป็นกระบวนการค้นหาว่า

**มันทำอะไร**

**มันทำเมื่อใด**

**อะไรเป็นตัวกระตุ้น**

**มันมีข้อจำกัดหรือไม่**

และสำคัญที่สุด

**สิ่งที่สำนักงานคิดว่าเป็นกฎนั้นถูกต้องจริงหรือไม่**

# 4. การจำแนกความผิดปกติ

สำนักงานแบ่ง Deviation เพื่อความสะดวกในการจัดเก็บข้อมูล แต่ยอมรับว่าการจำแนกนี้อาจไม่สะท้อนธรรมชาติที่แท้จริงของสิ่งเหล่านั้น

## Object — วัตถุผิดปกติ

สิ่งที่มีรูปร่างเป็นวัตถุหรือเครื่องมือ

ตัวอย่าง:

โทรศัพท์ที่รับสายจากอนาคต

เทปคาสเซ็ตที่บันทึกเสียงของผู้เสียชีวิต

กระจกที่สะท้อนห้องในช่วงเวลาอื่น

หนังสือที่มีเนื้อหาเปลี่ยนตามผู้อ่าน

ปืนที่กระสุนไม่ทำร้ายร่างกาย แต่ลบความทรงจำบางส่วนของเป้าหมาย

Object บางชิ้นสามารถนำมาใช้เป็นเครื่องมือของสำนักงานได้

แต่การใช้งานทุกครั้งมีความเสี่ยง

---

## Entity — ตัวตนผิดปกติ

สิ่งที่แสดงพฤติกรรมคล้ายสิ่งมีชีวิตหรือจิตสำนึก

Entity ไม่จำเป็นต้องมีร่างกาย

บาง Entity สามารถพูดคุย ต่อรอง โกหก เรียนรู้ หรือสร้างความสัมพันธ์กับมนุษย์ได้

สำนักงานมี Entity จำนวนหนึ่งที่อยู่ในสถานะร่วมมือหรือเป็นกลาง

บางรายทำงานร่วมกับสำนักงานมาหลายสิบปี

อย่างไรก็ตาม

**ความสามารถในการสื่อสารไม่ได้หมายความว่ามันคิดแบบมนุษย์**

Entity อาจใช้คำศัพท์เดียวกับมนุษย์ แต่ให้ความหมายแตกต่างกันโดยสิ้นเชิง

---

## Phenomenon — ปรากฏการณ์ผิดปกติ

เหตุการณ์หรือสภาวะที่ไม่มีวัตถุหรือตัวตนต้นเหตุชัดเจน

เช่น:

เมืองบางส่วนหายไปเป็นเวลา 11 นาที

ฝนตกภายในอาคาร

คนจำนวนมากฝันถึงสถานที่เดียวกัน

ช่วงเวลาหนึ่งเกิดซ้ำ

เสียงวิทยุปรากฏพร้อมกันทั่วโลก

บุคคลทั้งหมดในพื้นที่ลืมเหตุการณ์เดียวกัน

Phenomenon บางชนิดเกิดเพียงครั้งเดียว

บางชนิดเกิดซ้ำเป็นรอบ

---

## Location — พื้นที่ผิดปกติ

สถานที่ซึ่งกฎของ Layer Zero ทำงานผิดไปจากปกติ

เช่น:

ทางเดินที่ไม่มีจุดสิ้นสุด

อาคารที่มีจำนวนห้องเปลี่ยนไป

สถานีรถไฟที่ปรากฏเฉพาะบางเวลา

หมู่บ้านที่ไม่ปรากฏบนแผนที่แต่สามารถเดินทางเข้าไปได้

สำนักงานถกเถียงกันว่า Location ควรเป็นหมวดแยก หรือเป็นเพียง Phenomenon ประเภทหนึ่ง

# 5. ระดับความเข้าใจ

สำนักงานไม่จำแนกสิ่งผิดปกติจาก “พลัง” เพียงอย่างเดียว

ข้อมูลที่สำคัญกว่าคือระดับความเข้าใจ

ตัวอย่างสถานะ:

**Observed**  
ยืนยันว่าปรากฏการณ์มีอยู่จริง

**Patterned**  
ตรวจพบรูปแบบหรือเงื่อนไขบางอย่าง

**Interpreted**  
มีแบบจำลองที่สามารถอธิบายพฤติกรรมส่วนใหญ่ได้

**Operational**  
สามารถนำความรู้เกี่ยวกับมันมาใช้งานได้ในระดับหนึ่ง

**Unknown**  
ข้อมูลไม่เพียงพอหรือแบบจำลองเดิมถูกพิสูจน์ว่าผิด

แม้แต่สิ่งที่อยู่ในสถานะ Operational ก็ไม่ถือว่า “เข้าใจอย่างสมบูรณ์”

สำนักงานเคยสูญเสียบุคลากรจำนวนมากจากการเชื่อว่ารู้กฎของ Deviation ดีพอแล้ว

# 6. สำนักงาน

องค์กรลับที่ทำหน้าที่ตรวจสอบ ศึกษา ควบคุม ปกปิด และเมื่อจำเป็น กำจัดผลกระทบจาก Deviation

ชื่อทางการขององค์กรยังไม่จำเป็นต้องเปิดเผยในช่วงต้นเรื่อง

เจ้าหน้าที่ส่วนใหญ่เรียกง่าย ๆ ว่า

**สำนักงาน**

สำนักงานดำเนินงานข้ามประเทศและมีความสัมพันธ์ลับกับรัฐบาล หน่วยข่าวกรอง กองทัพ มหาวิทยาลัย ห้องทดลอง และองค์กรอื่น

รัฐบาลบางประเทศรู้ว่าสำนักงานมีอยู่

แต่ระดับความรู้แตกต่างกันอย่างมาก

แม้แต่เจ้าหน้าที่ระดับสูงของรัฐบาลก็ไม่ได้รับข้อมูลทุกอย่าง

สำนักงานมีหลักการพื้นฐานว่า:

**หน้าที่ของสำนักงานไม่ใช่ทำให้มนุษย์เข้าใจโลก แต่ทำให้มนุษย์สามารถใช้ชีวิตต่อไปได้โดยไม่จำเป็นต้องเข้าใจมัน**

# 7. การปกปิด

เมื่อเกิดเหตุผิดปกติ สำนักงานจะพยายามสร้างคำอธิบายที่เข้ากับโลกปกติ

อุบัติเหตุ

อาคารถล่ม

สารเคมี

โรคทางระบบประสาท

ภาพตัดต่อ

AI-generated content

ข่าวปลอม

Urban legend

ในหลายกรณี วิธีที่มีประสิทธิภาพกว่าคือ **ทำให้ความจริงกลายเป็นเพียงหนึ่งในคำอธิบายจำนวนมาก**

ดังนั้นเรื่องจริงบางเรื่องยังคงอยู่บนอินเทอร์เน็ต

แต่ไม่มีใครสามารถพิสูจน์ได้ว่าเรื่องไหนจริง

# 8. ความสัมพันธ์กับโลกจริง

สามารถอ้างอิงเหตุการณ์ลึกลับ ตำนาน หรือปริศนาที่มีอยู่จริงเพื่อสร้างความสมจริง เช่น:

Number Stations

UVB-76

Wow! Signal

เหตุการณ์บุคคลสูญหาย

ตำนานเมือง

ภาพถ่ายหรือคลิปที่ไม่สามารถอธิบายได้ในทันที

สถานที่ร้าง

สัญญาณวิทยุปริศนา

เหตุการณ์ทางประวัติศาสตร์ที่มีข้อมูลไม่สมบูรณ์

อย่างไรก็ตาม ต้องแยก “ข้อเท็จจริงในโลกจริง” ออกจาก “คำอธิบายในจักรวาลนิยาย”

ตัวอย่าง:

เหตุการณ์จริงอาจมีคำอธิบายทางวิทยาศาสตร์ที่สมเหตุสมผล

ในจักรวาลนิยาย คำอธิบายดังกล่าวอาจยังถูกต้อง แต่สำนักงานพบรายละเอียดเพิ่มเติมที่ประชาชนไม่เคยได้รับรู้

วิธีนี้ควรถูกใช้มากกว่าการประกาศว่าทฤษฎีสมคบคิดในโลกจริงเป็นความจริงทั้งหมด

# 9. การสื่อสารกับ Entity

สำนักงานสามารถสื่อสารกับ Entity บางประเภทได้

การสื่อสารอาจเกิดผ่าน:

ภาษาพูด

ข้อความ

ภาพ

ความฝัน

คลื่นวิทยุ

วัตถุ

มีระเบียบการเจรจาเฉพาะสำหรับ Entity

หลักสำคัญคือ:

**ห้ามถือว่าคำตอบของ Entity เป็นความจริง**

**ห้ามถือว่า Entity เข้าใจคำถามในความหมายเดียวกับมนุษย์**

**ห้ามทำข้อตกลงโดยใช้คำที่ไม่ได้กำหนดความหมายอย่างชัดเจน**

**ห้ามเปิดเผยข้อมูลเกี่ยวกับมนุษยชาติโดยไม่จำเป็น**

Entity บางรายกลายเป็นแหล่งข่าวของสำนักงาน

บางรายแลกข้อมูลกับสิ่งของ

บางรายต้องการประสบการณ์ ความทรงจำ เรื่องเล่า หรือสิ่งที่มนุษย์ไม่เข้าใจว่าเหตุใดมันจึงมีค่า

บาง Entity สามารถมีความสัมพันธ์ระยะยาวกับเจ้าหน้าที่ได้

แต่ไม่ควรทำให้ความสัมพันธ์ดังกล่าวพิสูจน์โดยอัตโนมัติว่า Entity นั้นเป็นมิตร

อยู่ภายใต้การดูแลของสำนักงานมาตั้งแต่ก่อนการก่อตั้งองค์กรในรูปแบบปัจจุบัน

มีความรู้เกี่ยวกับ Deviation จำนวนมาก

ให้ข้อมูลเป็นครั้งคราว

มักเรียกร้องสิ่งตอบแทนที่ดูไม่มีความเกี่ยวข้อง เช่น ชา หนังสือ เรื่องเล่า หรือการกระทำบางอย่างในเวลาที่กำหนด

ไม่ทราบวัตถุประสงค์ที่แท้จริง

เมื่อพบนนท์ครั้งแรกกล่าวว่า:

“คราวนี้มาเร็วกว่าครั้งก่อน”

# 11. ตัวอย่าง Object สำคัญ

## O-044 “โทรศัพท์สีแดง”

โทรศัพท์แบบหมุนซึ่งไม่เชื่อมต่อกับระบบโทรศัพท์ใด

สามารถรับสายจากบุคคลที่อยู่ในอนาคตบางรูปแบบ

ภายหลังสำนักงานพบว่าโทรศัพท์ไม่ได้ทำนายอนาคต

มันรับข้อมูลจาก “อนาคตที่เคยเกิดขึ้น”

การเปลี่ยนแปลงเหตุการณ์ตามข้อมูลจากโทรศัพท์สามารถทำให้อนาคตดังกล่าวไม่เกิดขึ้น

## O-108 “เทปผู้เสียชีวิต”

เครื่องเล่นเทปที่สามารถบันทึกเสียงช่วงก่อนการเสียชีวิตของบุคคลในบริเวณนั้น

สำนักงานใช้เป็นเครื่องมือด้านการสืบสวน

ยังไม่ทราบว่าข้อมูลถูกดึงมาจากอดีตจริง ความทรงจำของสถานที่ หรือแหล่งอื่น

มีอย่างน้อยหนึ่งเหตุการณ์ที่สิ่งซึ่งอยู่ในเสียงบันทึกรับรู้ว่ามีคนกำลังฟังเทปอยู่

# 12. ตัวละครหลัก — นนท์

ชายหนุ่มอายุประมาณ 24 ปี

เดิมเป็นคนธรรมดาและไม่มีความเกี่ยวข้องกับสำนักงาน

สำนักงานพบเขาหลังเกิด Deviation ในร้านสะดวกซื้อที่เขาทำงานกะกลางคืน

จากการตรวจสอบไม่พบพลังเหนือธรรมชาติ การกลายพันธุ์ การครอบงำ หรือคุณสมบัติทางกายภาพผิดปกติ

แต่เขามีคุณสมบัติหนึ่งที่สำนักงานไม่สามารถอธิบายได้

**Deviation ที่บิดเบือนการรับรู้ของมนุษย์ไม่สามารถทำให้นนท์มองข้ามความผิดปกติได้ตามปกติ**

หากสิ่งหนึ่งทำให้มนุษย์มองไม่เห็น นนท์อาจเห็น

หากสิ่งหนึ่งทำให้มนุษย์ลืม นนท์อาจจำได้

หากสถานที่ทำให้ผู้พบเห็นรู้สึกว่าทุกอย่างปกติ นนท์สามารถรับรู้ว่ามีบางอย่างผิด

สิ่งนี้ไม่ถือเป็น “ภูมิคุ้มกัน”

Deviation ยังสามารถทำร้าย หลอก หรือฆ่าเขาได้

เขาเพียงรับรู้บางสิ่งในรูปแบบที่มนุษย์ทั่วไปไม่สามารถทำได้

สำนักงานยังไม่ทราบสาเหตุ

# 14. หลักการของฉาก Action

อาวุธปืนและเทคโนโลยีของมนุษย์ยังมีประโยชน์

แต่ไม่ใช่คำตอบของทุกสถานการณ์

การต่อสู้กับ Deviation ควรมีลักษณะเป็น

**การแก้ปริศนาในสถานการณ์ที่สามารถตายได้**

บาง Entity สามารถถูกยิงตาย

บาง Entity ไม่มีร่างกายให้ยิง

บางชนิดฟื้นตัว

บางชนิดแข็งแกร่งขึ้นเมื่อถูกโจมตี

บางชนิดรับรู้ตำแหน่งของผู้โจมตีจากการถูกโจมตี

บางชนิดไม่ได้เป็นศัตรู แต่ตอบสนองต่อพฤติกรรมของมนุษย์ตามกฎบางอย่าง

ดังนั้นข้อมูลจากการสืบสวนมักเป็นสิ่งที่ทำให้ตัวละครรอดชีวิต

# 15. Cosmic Horror

จักรวาลมีสิ่งที่สำนักงานเรียกชั่วคราวว่า

**Great Phenomena — มหาปรากฏการณ์**

เป็นสิ่งหรือปรากฏการณ์ระดับที่มนุษย์ไม่สามารถทำความเข้าใจได้อย่างสมบูรณ์

ไม่ควรปฏิบัติต่อสิ่งเหล่านี้เหมือน “บอสใหญ่”

บางอย่างอาจไม่มีแนวคิดเรื่องมนุษย์ด้วยซ้ำ

บางอย่างอาจมีขนาดใหญ่จนคำว่า “สิ่งมีชีวิต” ไม่มีความหมาย

บางอย่างอาจไม่ได้อยู่ภายใต้เวลาแบบเดียวกับมนุษย์

สำนักงานมีข้อมูลเพียงเศษเสี้ยวเกี่ยวกับพวกมัน

และข้อมูลบางอย่างถูกจัดเป็นความลับแม้แต่ภายในองค์กร

# 16. หลักการสำคัญที่สุดของจักรวาล

## สำนักงานไม่รู้ทุกอย่าง

แฟ้มจำนวนมากไม่มีคำตอบ

ทฤษฎีสามารถผิดได้

นักวิจัยสามารถตีความหลักฐานผิดได้

Entity สามารถโกหกได้

เอกสารของสำนักงานสามารถมีข้อมูลขัดแย้งกันเอง

สิ่งที่เชื่อว่าเป็น Object อาจเป็น Entity

สิ่งที่เชื่อว่าเป็น Entity อาจเป็นเพียงอวัยวะส่วนหนึ่งของบางสิ่ง

สิ่งที่คิดว่าสามารถควบคุมได้อาจเพียงยอมให้มนุษย์คิดว่าควบคุมมันได้

และความรู้ใหม่สามารถล้มล้างสิ่งที่สำนักงานเชื่อมาหลายสิบปีได้

หลักการในการเขียนคือ:

**ยิ่งสำนักงานรู้มากขึ้น โลกไม่ควรดูเรียบง่ายขึ้น แต่ควรทำให้เห็นว่าพื้นที่ซึ่งยังไม่รู้นั้นกว้างใหญ่เพียงใด**

# 17. ปริศนาหลักระยะยาว

ความสามารถของนนท์อาจไม่ใช่อุบัติเหตุ

Entity บางรายดูเหมือนรู้จักเขาก่อนที่จะพบกัน

มีหลักฐานเกี่ยวกับตัวเขาปรากฏในสถานที่หรือช่วงเวลาที่เป็นไปไม่ได้

มีความเป็นไปได้ว่าเหตุการณ์ Deviation หลายคดีไม่ได้เกิดขึ้นรอบตัวเขาโดยบังเอิญ

คำถามระยะยาวประกอบด้วย:

เหตุใดนนท์จึงมองเห็นสิ่งที่มนุษย์ไม่ควรเห็น?

Layer Zero เกิดขึ้นตามธรรมชาติจริงหรือไม่?

เหตุใดสมองมนุษย์จึงมีแนวโน้มมองข้าม Deviation?

The Deep คืออะไร?

สำนักงานก่อตั้งขึ้นจากเหตุการณ์ใด?

ใครหรืออะไรเป็นผู้ให้ข้อมูลเกี่ยวกับ Deviation แก่มนุษย์เป็นครั้งแรก?

เหตุใด Entity บางรายจึงดูเหมือนรู้อนาคตของนนท์?

และคำถามที่อันตรายที่สุด:

**มนุษย์มองไม่เห็นความจริงเพราะวิวัฒนาการมาเช่นนั้น หรือมีบางสิ่งทำให้มนุษย์มองไม่เห็นมัน?**

ไม่ควรเฉลยคำถามเหล่านี้อย่างรวดเร็ว

คำตอบของปริศนาหนึ่งควรสร้างคำถามใหม่ที่ใหญ่กว่าเดิมเสมอ

# WORLD SETTING ADDENDUM — RESONANT (ผู้สอดคล้อง)

ประเภทเอกสาร: Worldbuilding / Ability System
สถานะ: CANON
จักรวาล: โลกชั้นที่ศูนย์ (Layer Zero)

เอกสารนี้เป็นข้อมูล Canon เพิ่มเติมของจักรวาลนิยาย ใช้ร่วมกับ WORLD SETTING, ORGANIZATION SETTING และ CHARACTER SETTING — นนท์

ห้ามตีความ Resonant เป็นระบบเวทมนตร์ ระบบมานา หรือระบบพลังแบบเกม

---

## 1. RESONANT คืออะไร

Resonant (ผู้สอดคล้อง) เป็นคำที่สำนักงานใช้เรียกมนุษย์ที่มีคุณสมบัติในการตอบสนองต่อ Deviation บางประเภทแตกต่างจากมนุษย์ทั่วไป

บุคคลเหล่านี้ไม่ได้มีพลังเหนือธรรมชาติที่สามารถใช้งานได้ด้วยตนเอง

ความสามารถของพวกเขาเกิดขึ้นเมื่อมีปฏิสัมพันธ์กับ Object หรือ Entity ที่มีคุณสมบัติเข้ากันได้

ตัวอย่างเช่น:

- สามารถใช้งาน Object ที่ไม่ตอบสนองต่อมนุษย์ทั่วไป
- สามารถกระตุ้นกลไกบางอย่างของ Object
- สามารถรับรู้ข้อความจาก Entity ที่มนุษย์ทั่วไปไม่สามารถสื่อสารด้วยได้
- สามารถทำหน้าที่เป็นตัวกลางในการสื่อสารระหว่างมนุษย์กับ Entity
- สามารถทำให้ Object บางชิ้นแสดงคุณสมบัติที่ไม่ปรากฏเมื่ออยู่กับผู้ใช้งานคนอื่น

สำนักงานเรียกปรากฏการณ์นี้ว่า Resonance (ภาวะสอดคล้อง)

Resonance ไม่ใช่พลังงานที่สามารถวัดเป็นปริมาณได้โดยตรง แต่เป็นชื่อเรียกชั่วคราวของความสัมพันธ์ระหว่างมนุษย์กับ Deviation

สำนักงานยังไม่สามารถอธิบายกลไกทั้งหมดได้

---

## 2. ความแตกต่างระหว่าง RESONANT และ UNFILTERED

Resonant และ Unfiltered เป็นคุณสมบัติคนละประเภท

UNFILTERED:

บุคคลที่กลไกจำกัดการรับรู้ของ Layer Zero หรือ The Veil ทำงานไม่สมบูรณ์

บุคคลประเภทนี้อาจมองเห็นหรือจดจำสิ่งที่มนุษย์ทั่วไปไม่สามารถรับรู้ได้

นนท์เป็น Unfiltered Individual

RESONANT:

บุคคลที่สามารถเกิดปฏิสัมพันธ์กับ Deviation บางประเภทได้แตกต่างจากมนุษย์ทั่วไป

Resonant อาจใช้งาน Object ได้โดยไม่สามารถมองเห็น Entity ที่ถูก The Veil ปิดบัง

ในทางกลับกัน Unfiltered อาจมองเห็น Entity ดังกล่าว แต่ไม่สามารถใช้งาน Object ที่ Resonant ใช้ได้

ความแตกต่างสำคัญ:

- Unfiltered เกี่ยวข้องกับการรับรู้
- Resonant เกี่ยวข้องกับการปฏิสัมพันธ์
- Unfiltered ไม่จำเป็นต้องเป็น Resonant
- Resonant ไม่จำเป็นต้องเป็น Unfiltered
- บุคคลหนึ่งอาจมีคุณสมบัติทั้งสองประเภทได้ แต่พบได้น้อยมาก

นนท์ไม่ได้เป็น Resonant โดยอัตโนมัติ

---

## 3. หลักการทำงานของ RESONANCE

Object บางชิ้นไม่ได้ตอบสนองต่อมนุษย์ทุกคนในรูปแบบเดียวกัน

สำนักงานพบว่า Object สามารถแบ่งตามเงื่อนไขการใช้งานได้หลายลักษณะ เช่น:

1. Object ที่มนุษย์ทั่วไปสามารถใช้งานได้
2. Object ที่ต้องใช้เงื่อนไขเฉพาะในการกระตุ้น
3. Object ที่ตอบสนองต่อบุคคลบางคนเท่านั้น
4. Object ที่ตอบสนองต่อ Resonant ได้หลายคน
5. Object ที่ตอบสนองต่อ Resonant เพียงคนเดียวในช่วงเวลาหนึ่ง
6. Object ที่สามารถเปลี่ยนผู้ใช้งานได้
7. Object ที่ตอบสนองต่อผู้ใช้งานคนเดิมเพียงครั้งเดียว

Resonance ไม่ใช่การรับประกันว่า Object จะเชื่อฟังผู้ใช้

Object บางชิ้นอาจมีพฤติกรรมคล้ายการเลือกผู้ใช้งาน แต่สำนักงานไม่ถือว่าพฤติกรรมดังกล่าวเป็นหลักฐานยืนยันว่า Object มีจิตสำนึก

Object ที่ดูเหมือนเลือกผู้ใช้งานอาจเป็น Entity หรืออาจมีกลไกที่สำนักงานยังไม่เข้าใจ

---

## 4. RESONANT ไม่สามารถใช้ OBJECT ทุกชิ้น

Resonant แต่ละคนมีความเข้ากันได้กับ Object แตกต่างกัน

Resonant คนหนึ่งอาจสามารถใช้งานโทรศัพท์ผิดปกติได้ แต่ไม่สามารถใช้งานเครื่องบันทึกเสียงผิดปกติอีกชิ้นหนึ่ง

Resonant อีกคนอาจสามารถใช้งานเครื่องบันทึกเสียงได้ แต่โทรศัพท์ไม่เคยตอบสนองต่อเขาเลย

สำนักงานไม่สามารถทำนายความเข้ากันได้จาก:

- ความแข็งแรง
- สติปัญญา
- อายุ
- เพศ
- บุคลิกภาพ
- ประสบการณ์ภาคสนาม
- ความรู้เกี่ยวกับ Deviation

การใช้งาน Object ได้หนึ่งชิ้นไม่ได้หมายความว่าบุคคลนั้นจะสามารถใช้งาน Object ชิ้นอื่นได้

ความเข้ากันได้ต้องได้รับการตรวจสอบเป็นรายบุคคลและราย Object

---

## 5. RESONANT กับ ENTITY

Entity บางประเภทสามารถสื่อสารกับมนุษย์ทั่วไปได้โดยตรง

แต่ Entity บางประเภทไม่สามารถถ่ายทอดความหมายผ่านภาษาหรือประสาทสัมผัสของมนุษย์ตามปกติ

Resonant บางคนสามารถทำหน้าที่เป็นตัวกลางในการสื่อสารกับ Entity เหล่านี้ได้

รูปแบบการสื่อสารอาจประกอบด้วย:

- เสียง
- ข้อความ
- ภาพ
- ความรู้สึก
- ความทรงจำ
- ความฝัน
- การเปลี่ยนแปลงของวัตถุ
- วิธีอื่นที่สำนักงานยังไม่สามารถอธิบายได้

Resonant ไม่ได้สามารถสื่อสารกับ Entity ทุกประเภท

บางคนสามารถสื่อสารกับ Entity ได้เพียงรายเดียว

บางคนสามารถรับรู้ความต้องการของ Entity แต่ไม่สามารถตอบกลับ

บางคนสามารถรับรู้ข้อความได้ แต่ไม่สามารถอธิบายได้ว่าตนเองได้รับข้อมูลผ่านช่องทางใด

การสื่อสารกับ Entity ไม่ได้หมายความว่า Resonant เข้าใจความหมายที่แท้จริงของข้อความทั้งหมด

Entity ยังสามารถโกหก หลอกลวง หรือใช้คำศัพท์ที่มีความหมายแตกต่างจากภาษามนุษย์ได้

---

## 6. RESONANT ภายในสำนักงาน

สำนักงานรู้จักและใช้งาน Resonant มานานก่อนเหตุการณ์ร้านสะดวกซื้อของนนท์

Resonant ไม่ใช่กลุ่มคนที่เพิ่งถูกค้นพบหลังจากนนท์เข้าสำนักงาน

สำนักงานมีบุคลากร Resonant อยู่ในหลายฝ่าย

ฝ่ายวิจัย:

ใช้ Resonant ในการทดลองกับ Object ที่ไม่ตอบสนองต่อมนุษย์ทั่วไป

ฝ่ายสืบสวน:

ใช้ Resonant ในคดีที่ต้องอาศัย Object เฉพาะทาง

ฝ่ายกักกัน:

ใช้ Resonant ในการปฏิบัติตาม Containment Protocol ของ Deviation บางรายการ

ฝ่ายสื่อสารกับตัวตน:

ใช้ Resonant เป็นผู้เจรจาหรือตัวกลางในการสื่อสารกับ Entity

Resonant ไม่ได้เป็นเจ้าหน้าที่ภาคสนามโดยอัตโนมัติ

บุคคลเหล่านี้ยังต้องได้รับการฝึกตามหน้าที่

Resonant ที่ใช้งาน Object ได้อาจไม่มีทักษะการต่อสู้ การสืบสวน หรือความรู้ทางวิทยาศาสตร์

สำนักงานจึงไม่สามารถใช้ Resonant แทนบุคลากรทั่วไปได้ทั้งหมด

---

## 7. การตรวจพบ RESONANT

สำนักงานยังไม่มีวิธีตรวจ Resonance ที่แม่นยำสมบูรณ์โดยไม่ต้องอาศัย Deviation

การตรวจเลือดหรือการสแกนสมองไม่สามารถยืนยันได้ว่าบุคคลหนึ่งเป็น Resonant

การประเมินต้องอาศัยการทดสอบปฏิสัมพันธ์กับ Object หรือ Entity ที่ได้รับอนุญาต

หาก Object แสดงพฤติกรรมแตกต่างจากการทดสอบกับมนุษย์ทั่วไป สำนักงานจะบันทึกผลและทดลองซ้ำ

การตอบสนองเพียงครั้งเดียวไม่เพียงพอต่อการยืนยัน

ต้องตรวจสอบว่าการตอบสนองเกิดจากบุคคลจริง ไม่ใช่เงื่อนไขอื่นที่เกิดขึ้นพร้อมกัน

สำนักงานเคยจัดประเภทบุคคลเป็น Resonant ผิดพลาดมาแล้ว

---

## 8. ความเสี่ยงของ RESONANCE

Resonance ไม่ได้ทำให้ Object ปลอดภัยขึ้น

ในบางกรณี Resonance ทำให้บุคคลสามารถกระตุ้นกลไกที่มนุษย์ทั่วไปไม่สามารถกระตุ้นได้

Object ที่ไม่มีอันตรายเมื่ออยู่กับมนุษย์ทั่วไปอาจกลายเป็นสิ่งที่มีผลกระทบรุนแรงเมื่อ Resonant ใช้งาน

ความเสี่ยงอาจประกอบด้วย:

- การสูญเสียความทรงจำ
- การเปลี่ยนแปลงทางร่างกาย
- การถูก Entity รับรู้
- การเกิดผลกระทบต่อพื้นที่
- การเปลี่ยนแปลงของเวลา
- การสูญเสียความสามารถในการใช้งาน Object
- การเกิดเงื่อนไขใหม่ที่สำนักงานไม่เคยพบมาก่อน

สำนักงานไม่อนุญาตให้ Resonant ใช้งาน Object โดยไม่มี Protocol แม้จะเคยใช้งานสำเร็จมาแล้วหลายครั้ง

---

## 9. ความสัมพันธ์กับ THE VEIL

ข้อมูลระดับ AUTHOR-ONLY CANON:

Resonance และ Unfiltered Perception เกี่ยวข้องกับความสัมพันธ์ระหว่างมนุษย์กับ Layer Zero แต่ส่งผลคนละด้าน

Unfiltered Perception เกี่ยวข้องกับข้อจำกัดในการรับรู้ข้อมูล

Resonance เกี่ยวข้องกับความสามารถในการเกิดปฏิสัมพันธ์กับ Deviation

มนุษย์ทั่วไปอาจไม่สามารถมองเห็น Object บางชิ้นเพราะ The Veil

Unfiltered อาจมองเห็น Object ดังกล่าว แต่ไม่สามารถกระตุ้นการทำงานของมัน

Resonant อาจสามารถกระตุ้นการทำงานของ Object ได้ แต่ไม่จำเป็นต้องรับรู้สิ่งที่ The Veil ปิดบัง

สำนักงานยังไม่เข้าใจกลไกทั้งหมดของ Resonance และยังไม่สามารถยืนยันความสัมพันธ์ระหว่าง Resonance กับ The Veil ได้อย่างสมบูรณ์

ห้ามให้เจ้าหน้าที่ทั่วไปทราบความจริงระดับผู้เขียนนี้ตั้งแต่ต้นเรื่อง

## 10. ตัวอย่างการใช้งานในเนื้อเรื่อง

ตัวอย่างที่หนึ่ง:

สำนักงานมี Object ที่สามารถแสดงภาพเหตุการณ์ในอดีตของสถานที่ได้ แต่ไม่ตอบสนองต่อมนุษย์ทั่วไป

Resonant คนหนึ่งสามารถกระตุ้นมันได้

ภาพที่ปรากฏแสดงห้องว่างเปล่า

นนท์กลับมองเห็นบุคคลหนึ่งยืนอยู่ภายในภาพ

Resonant ไม่สามารถมองเห็นบุคคลนั้น

นนท์ไม่สามารถใช้งาน Object ได้

ทั้งสองจึงต้องทำงานร่วมกัน

ตัวอย่างที่สอง:

Entity ไม่สามารถพูดภาษามนุษย์ได้ แต่ Resonant คนหนึ่งสามารถรับรู้ข้อความของมันผ่านความทรงจำ

นนท์สามารถมองเห็นรูปร่างของ Entity แต่ไม่เข้าใจว่ามันกำลังสื่อสารอะไร

Resonant สามารถเข้าใจข้อความ แต่ไม่สามารถมองเห็นสิ่งที่กำลังพูดกับตนเอง

ทั้งสองมีข้อมูลคนละส่วน

ตัวอย่างที่สาม:

Object ชิ้นหนึ่งตอบสนองต่อ Resonant เพียงคนเดียว

เมื่อบุคคลดังกล่าวเสียชีวิต สำนักงานไม่สามารถใช้งาน Object ได้อีก

หลายปีต่อมา Object กลับตอบสนองต่อเจ้าหน้าที่คนใหม่

สำนักงานต้องสืบสวนว่า Object เปลี่ยนผู้ใช้งานได้อย่างไร และการเสียชีวิตของผู้ใช้งานคนก่อนเกี่ยวข้องกับเงื่อนไขดังกล่าวหรือไม่

ตัวอย่างเหล่านี้เป็นแนวทางในการสร้างคดี ไม่ใช่เหตุการณ์ที่เกิดขึ้นแล้วใน Canon เว้นแต่ผู้เขียนจะกำหนดเพิ่มเติม

## 11. ข้อกำหนด CANON ที่ห้ามขัดแย้ง

1. Resonant เป็นมนุษย์ที่สามารถเกิดปฏิสัมพันธ์กับ Deviation บางประเภทได้แตกต่างจากมนุษย์ทั่วไป

2. ความสามารถหลักของ Resonant คือการใช้งาน Object เฉพาะชิ้นและการสื่อสารกับ Entity บางประเภท

3. Resonant ไม่มีพลังเหนือธรรมชาติที่สามารถใช้งานได้โดยไม่ต้องอาศัย Deviation

4. Resonant ไม่สามารถใช้งาน Object ทุกชิ้น

5. ความเข้ากันได้ต้องตรวจสอบเป็นรายบุคคลและราย Object หรือ Entity

6. Resonance ไม่ใช่ภูมิคุ้มกันต่ออันตราย

7. Resonant ไม่จำเป็นต้องมองเห็นสิ่งที่ The Veil ปิดบัง

8. Unfiltered ไม่จำเป็นต้องมี Resonance

9. บุคคลหนึ่งอาจมีคุณสมบัติทั้ง Resonant และ Unfiltered ได้ แต่พบได้น้อยมาก

10. สำนักงานมี Resonant เป็นบุคลากรอยู่แล้วก่อนพบน นท์ในเหตุการณ์ร้านสะดวกซื้อ

11. Resonant ไม่ได้มีความสามารถในการสืบสวนหรือต่อสู้โดยอัตโนมัติ

12. การใช้งาน Object สำเร็จไม่ได้หมายความว่าผู้ใช้เข้าใจกฎของ Object ทั้งหมด

13. Resonance ไม่ใช่ระบบระดับพลัง ไม่มีการแบ่ง Resonant เป็นแรงก์ตามความแข็งแกร่ง

14. Resonant แต่ละคนไม่จำเป็นต้องมีความสามารถเหมือนกัน

15. ห้ามเขียนให้นนท์สามารถใช้งาน Object ทุกชิ้นได้เพียงเพราะเขาเป็น Unfiltered

---

## 12. ผลต่อบทบาทของนนท์

ในช่วงแรก นนท์อาจเข้าใจว่าตนเองเป็น Resonant ประเภทหนึ่ง

เขาเห็นเจ้าหน้าที่สำนักงานบางคนสามารถใช้งาน Object ที่คนธรรมดาใช้ไม่ได้ และสื่อสารกับ Entity ได้

แต่เมื่อเข้ารับการทดสอบ นนท์กลับไม่สามารถใช้งาน Object หลายชิ้นที่ Resonant คนอื่นใช้งานได้

ขณะเดียวกัน เขากลับมองเห็นบางสิ่งระหว่างการทดสอบที่ไม่มีเจ้าหน้าที่คนใดรับรู้

สำนักงานจึงเริ่มเข้าใจว่านนท์ไม่ได้มีความสามารถประเภทเดียวกับบุคลากรพิเศษที่องค์กรรู้จักอยู่แล้ว

Resonant ทำให้สำนักงานสามารถปฏิสัมพันธ์กับบางสิ่งได้

Unfiltered ทำให้นนท์สามารถรับรู้บางสิ่งที่สำนักงานไม่รู้ว่ามีอยู่

ความสามารถทั้งสองประเภทสามารถทำงานร่วมกัน แต่ไม่สามารถทดแทนกันได้

นี่เป็นหลักการสำคัญของระบบความสามารถในจักรวาลเรื่องนี้

# ARC 01 — ทะเบียนตัวละครและสถานะส่งต่อ

> ไม่ใช่การยืนยันตัวตนย้อนหลังหรือการเลื่อนเป็น established Canon. ดู [สรุปคดี](case-summary.md).

| บุคคล | บทบาทใน Arc | สถานะปลาย Arc / สิ่งที่ต้องรักษา |
|---|---|---|
| นนท์ / นนทกร วัฒนากุล | พนักงานกะดึก พยานหลัก ผู้รับรู้ความผิดปกติบางชนิด | อยู่ระหว่างประเมินและพักสังเกตการณ์ ติดต่อแม่แล้ว ยังไม่เซ็นเป็นเจ้าหน้าที่; ไม่เฉลย author-only canon |
| ริน | เจ้าหน้าที่ประสานภาคสนาม | เสนอและนำวิธีส่งกลับแบบแยกยืนยัน; บันทึกความไม่ตรงกันแทนลบให้ลงตัว |
| อธิคม | ผู้ตรวจสอบและกำกับคำสั่ง | ดูแลขั้นตอนควบคุม/ตรวจสอบรายงานเก่าและการพักสังเกตการณ์นนท์ |
| เจ้าหน้าที่หญิงผมสั้น | เจ้าหน้าที่ร่วมทีม | ทำงานด้านกล้อง/การแยกบุคคล; ยังไม่กำหนดชื่อ |
| ภาคิน | ผู้ที่หน้าคล้ายธันวา | ถูกส่งกลับ แยกตรวจ และขอใช้ชื่อภาคิน; ไม่ยืนยันว่าเป็นธันวาคนเดิม |
| ธันวา | เจ้าหน้าที่อีกคนที่ถูกส่งกลับ | แยกตรวจจากภาคิน; แผลหรือใบหน้าไม่ใช่หลักฐานเด็ดขาด |
| ชายวัยกลางคนจากคดีเก่า | ผู้ปรากฏในพื้นที่ผิดปกติ | ถูกส่งกลับและแยกตรวจ; ความต่อเนื่องย้อนหลังไม่ยืนยัน |
| ชายเสื้อเทาผมเปียก | ลูกค้าซ้ำ/ผู้เกี่ยวข้องคดีเก่า | มีประวัติเสียชีวิตเมื่อ 11 ปีก่อน อยู่ด้านในก่อนปิด ปรากฏภาพครั้งที่ 38; ไม่ยืนยันเจตนาหรือกลไก |
| คนหน้าเหมือนนนท์หลายราย | ผู้ปรากฏต่างตำแหน่ง/บทบาท | ไม่รวมเป็นคนเดียวโดยอัตโนมัติ; คนในชุดพนักงานที่ทางออกหายจากการติดตาม |
| เสียงหลัง 142 | แหล่งเสียงคล้ายนนท์ | ไม่ยืนยันเจ้าของเสียง/จำนวนบุคคล |
| รินอีกคน / บุคคลอ้างตัว | แหล่งคำกล่าวและเอกสารที่ขัดกัน | ห้ามถือคำพูดหรือเอกสารที่นำมาให้เป็นหลักฐานยืนยันเอง |
| เงาสูงในกล้อง | สิ่งที่ปรากฏในภาพหลังนนท์ | ไม่ทราบตัวตน/ความเกี่ยวข้อง |

**คำเตือน:** หากแก้บท 10–12 ให้ตรวจจำนวนผู้ถูกส่งกลับ/ผู้ที่ยังอยู่/ผู้ที่ถูกแยกประเมินพร้อมกันทุกไฟล์.

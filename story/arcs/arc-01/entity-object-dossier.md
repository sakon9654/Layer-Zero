# ARC 01 — ENTITY & OBJECT DOSSIER

ประเภทเอกสาร: Deviation Dossier / Story Reference
จักรวาล: โลกชั้นที่ศูนย์
Arc: 01 — กะดึก
สถานะ: PROPOSED ARC CANON

## แนวคิดในการออกแบบ

Object และ Entity ของสำนักงานไม่ใช่อาวุธหรือเครื่องมือวิเศษที่สามารถแก้ปัญหาได้ทุกอย่าง

แต่ละรายการต้องมี:
- คุณสมบัติผิดปกติที่สังเกตได้
- เงื่อนไขการทำงาน
- ข้อจำกัด
- ความเสี่ยง
- Protocol
- ระดับความรู้ของสำนักงาน
- บทบาทต่อเนื้อเรื่อง

Object บางชิ้นสามารถใช้งานโดยมนุษย์ทั่วไปได้

Object บางชิ้นต้องใช้ Resonant ที่เข้ากันได้

การเป็น Unfiltered ไม่ได้ทำให้นนท์สามารถใช้งาน Object ทุกชิ้นได้

Entity ที่ร่วมมือกับสำนักงานไม่ได้หมายความว่าเป็นมิตรหรือพูดความจริงเสมอไป

# SECTION A — OBJECT ที่ใช้ใน ARC 01

## O-044 — โทรศัพท์สีแดง

สถานะ: EXISTING CANON
ประเภท: Object
การดูแล: ฝ่ายกักกัน / ฝ่ายวิจัย

### ลักษณะ

โทรศัพท์ตั้งโต๊ะสีแดง

รูปลักษณ์ภายนอกคล้ายโทรศัพท์ทั่วไป

ไม่มีหลักฐานว่าจำเป็นต้องเชื่อมต่อกับเครือข่ายโทรศัพท์ปกติเพื่อรับสายผิดปกติ

### คุณสมบัติ

O-044 สามารถรับสายจากอนาคตที่เคยเกิดขึ้นแล้ว

ข้อมูลจากสายโทรศัพท์อาจขัดแย้งกับลำดับเวลาปัจจุบัน

สำนักงานยังไม่สามารถใช้ O-044 ทำนายอนาคตได้อย่างน่าเชื่อถือ

### ข้อจำกัด

ไม่สามารถเลือกเวลาที่ต้องการรับสายได้อย่างอิสระ

ไม่สามารถยืนยันว่าข้อมูลจากสายโทรศัพท์จะเกิดขึ้นในลำดับเวลาปัจจุบัน

ไม่สามารถใช้แทนหลักฐานจากการสืบสวนปกติ

### บทบาทใน ARC 01

ปรากฏในห้องเก็บ Object ของสำนักงานหรือระหว่างการทดสอบที่ได้รับอนุญาต

นนท์ได้ยินเสียงโทรศัพท์ดังขึ้น

เจ้าหน้าที่ที่อยู่ด้วยกลับระบุว่าไม่มีสายเรียกเข้า

เมื่อเจ้าหน้าที่ตรวจสอบบันทึกการทำงาน พบว่า O-044 เคยรับสายจากหมายเลขเดียวกันในเวลาที่ไม่ตรงกับปัจจุบัน

เหตุการณ์นี้ใช้แสดงความแตกต่างระหว่างข้อมูลจากเครื่องมือกับการรับรู้ของนนท์

ไม่ควรใช้ O-044 เฉลยคดีร้านสะดวกซื้อโดยตรง

หมายเหตุ:
รายละเอียดการทดสอบนี้เป็นเหตุการณ์ใหม่ที่เสนอสำหรับ Arc ไม่ใช่คุณสมบัติที่ยืนยันแล้วว่าเกิดขึ้นทุกครั้ง

## O-108 — เทปผู้เสียชีวิต

สถานะ: EXISTING CANON
ประเภท: Object
การดูแล: ฝ่ายกักกัน / ฝ่ายวิจัย

### ลักษณะ

สื่อบันทึกเสียงผิดปกติ

สามารถบันทึกเสียงที่เกี่ยวข้องกับช่วงเวลาก่อนการเสียชีวิต

ในบางกรณี สิ่งที่ถูกบันทึกอาจรับรู้ถึงผู้ที่กำลังฟัง

### คุณสมบัติ

เสียงที่ปรากฏไม่ได้จำเป็นต้องตรงกับข้อมูลการเสียชีวิตที่สำนักงานมีอยู่

บางครั้งเสียงบันทึกมีปฏิกิริยาต่อผู้ฟัง

### ข้อจำกัด

ไม่สามารถใช้ระบุตำแหน่งหรือสาเหตุการเสียชีวิตได้อย่างสมบูรณ์

ไม่สามารถยืนยันได้ว่าเสียงที่ได้ยินเป็นคำพูดของผู้เสียชีวิตจริงทั้งหมด

ห้ามถือว่าเสียงบันทึกเป็นคำให้การที่เชื่อถือได้โดยอัตโนมัติ

### บทบาทใน ARC 01

สำนักงานนำ O-108 มาใช้ตรวจสอบข้อมูลเกี่ยวกับชายเสื้อเทา

ผลการตรวจสอบไม่ให้คำตอบตรงไปตรงมา

เทปบันทึกเสียงของชายเสื้อเทาพูดว่า:

"ผมไม่ได้อยู่ข้างล่างคนเดียว"

เมื่อเปิดฟังซ้ำ ประโยคดังกล่าวเปลี่ยนเป็น:

"ตอนนี้เขาไม่ได้อยู่ข้างล่างคนเดียว"

สำนักงานไม่สามารถยืนยันได้ว่าความเปลี่ยนแปลงเกิดจาก O-108 หรือ Deviation ประจำคดี

### หน้าที่เชิงเรื่องเล่า

เพิ่มข้อสงสัยว่าพื้นที่ชั้นใต้ดินยังมีบางสิ่งอยู่

ห้ามใช้เป็นหลักฐานยืนยันตัวตนของ "มัน"

## O-201 — เครื่องบันทึกรอยเหตุการณ์

สถานะ: NEW PROPOSED CANON
ประเภท: Object
การดูแล: ฝ่ายวิจัย
การใช้งาน: Resonant-compatible

### ลักษณะ

เครื่องมือขนาดใกล้เคียงวิทยุสื่อสารรุ่นเก่า

มีหน้าปัดกลไกและช่องแสดงภาพขนาดเล็ก

ไม่มีชื่อผู้ผลิตหรือหมายเลขรุ่น

### คุณสมบัติ

เมื่อถูกกระตุ้นโดย Resonant ที่เข้ากันได้ O-201 สามารถแสดงร่องรอยของเหตุการณ์ที่เคยเกิดขึ้นในพื้นที่จำกัด

ข้อมูลอาจปรากฏเป็นภาพนิ่ง เสียง หรือรายละเอียดบางส่วนของสภาพแวดล้อม

O-201 ไม่ได้แสดงอดีตทั้งหมด

มันแสดงเพียงร่องรอยที่ยังสามารถตรวจพบได้

### เงื่อนไข

ต้องใช้ Resonant ที่เข้ากันได้

ต้องมีตำแหน่งหรือวัตถุอ้างอิงจากเหตุการณ์

การทำงานไม่รับประกันว่าจะได้ผลทุกครั้ง

### ข้อจำกัด

ไม่สามารถเลือกช่วงเวลาได้อย่างแม่นยำ

ไม่สามารถย้อนดูเหตุการณ์ทั้งหมดตามต้องการ

ภาพที่แสดงอาจไม่สมบูรณ์

ไม่สามารถยืนยันได้ว่าสิ่งที่ไม่ปรากฏในภาพไม่เคยมีอยู่จริง

### บทบาทใน ARC 01

ใช้ใน EPISODE 05

เจ้าหน้าที่ Resonant กระตุ้น O-201 เพื่อตรวจสอบเหตุการณ์เมื่อสิบเอ็ดปีก่อน

เครื่องแสดงภาพทางเดินใต้ดิน

เจ้าหน้าที่เห็นทางเดินว่างเปล่า

นนท์กลับเห็นบุคคลหนึ่งเดินออกจากพื้นที่ในภาพ

การทำงานร่วมกันของทั้งสองคนทำให้ทีมพบเบาะแสใหม่

### ข้อกำหนด

O-201 ต้องไม่ทำหน้าที่เป็นกล้องย้อนเวลาที่สามารถไขทุกคดีได้

## O-202 — เหรียญตรวจสอบความต่อเนื่อง

สถานะ: NEW PROPOSED CANON
ประเภท: Object
การดูแล: ฝ่ายสืบสวน / ฝ่ายวิจัย

### ลักษณะ

เหรียญโลหะสีเงิน

ด้านหนึ่งมีหมายเลขประจำชิ้น

อีกด้านไม่มีลวดลาย

### คุณสมบัติ

เมื่อ O-202 อยู่ในพื้นที่ที่เกิดความไม่สอดคล้องของลำดับเหตุการณ์ ลวดลายหรือหมายเลขบนเหรียญอาจเปลี่ยนแปลง

สำนักงานใช้เป็นหลักฐานประกอบการตรวจสอบเหตุการณ์ที่เกี่ยวข้องกับเวลาและความทรงจำ

### ข้อจำกัด

ไม่สามารถบอกได้ว่าเหตุการณ์ใดถูกเปลี่ยนแปลง

ไม่สามารถบอกสาเหตุ

ไม่สามารถบอกทิศทางของเวลา

การเปลี่ยนแปลงไม่ได้หมายความว่าผู้ถือเหรียญกำลังอยู่ในอันตรายเสมอไป

### บทบาทใน ARC 01

ใช้ใน EPISODE 03 และ EPISODE 06

ระหว่างตรวจสอบร้าน เหรียญเปลี่ยนหมายเลขโดยไม่มีใครสังเกตเห็นขณะเกิดการเปลี่ยนแปลง

นนท์กลับจำหมายเลขเดิมได้

เหตุการณ์นี้ทำให้รินเริ่มบันทึกคำให้การของนนท์อย่างจริงจัง

### ข้อกำหนด

O-202 เป็นเครื่องมือบ่งชี้ความผิดปกติ ไม่ใช่อุปกรณ์ป้องกันการเปลี่ยนแปลงของเวลา

## O-203 — กระดาษคำถาม

สถานะ: NEW PROPOSED CANON
ประเภท: Object
การดูแล: ฝ่ายสื่อสารกับตัวตน
การใช้งาน: Resonant-compatible

### ลักษณะ

กระดาษสีขาวขนาด A5

ไม่พบความผิดปกติเมื่อใช้เขียนข้อความทั่วไป

### คุณสมบัติ

Resonant บางคนสามารถใช้ O-203 เป็นตัวกลางในการสื่อสารกับ Entity ที่ไม่สามารถพูดหรือเขียนภาษามนุษย์ได้โดยตรง

เมื่อผู้ใช้เขียนคำถามและวางกระดาษไว้ในพื้นที่ที่มี Entity เข้ากันได้ อาจมีข้อความตอบกลับปรากฏขึ้น

### ข้อจำกัด

ข้อความตอบกลับไม่จำเป็นต้องตรงกับคำถาม

Entity อาจไม่ตอบ

Entity อาจตอบด้วยข้อความที่มีหลายความหมาย

O-203 ไม่สามารถบังคับ Entity ให้พูดความจริง

### บทบาทใน ARC 01

ใช้ในฉากแนะนำฝ่าย Entity Liaison

เจ้าหน้าที่ Resonant สาธิตการใช้งานภายใต้การควบคุม

นนท์เห็นข้อความบางส่วนบนกระดาษก่อนเจ้าหน้าที่จะเริ่มการทดสอบ

เมื่อเจ้าหน้าที่อ่านคำตอบ ข้อความกลับไม่ตรงกับสิ่งที่นนท์เห็น

### หน้าที่เชิงเรื่องเล่า

แสดงให้เห็นว่าการสื่อสารกับ Entity และการรับรู้ความผิดปกติเป็นคนละคุณสมบัติ

ไม่จำเป็นต้องใช้ O-203 ในคดีร้านสะดวกซื้อโดยตรง

# SECTION B — ENTITY ที่อยู่ภายใต้การดูแลของสำนักงาน

## E-017 — คุณนาย

สถานะ: EXISTING CANON
ประเภท: Entity
การดูแล: ฝ่ายสื่อสารกับตัวตน

### ลักษณะ

Entity รูปร่างหญิงสูงอายุ

สามารถสนทนากับมนุษย์ได้

มีพฤติกรรมคล้ายหญิงสูงวัยที่คุ้นเคยกับการรับแขก

### พฤติกรรม

คุณนายสามารถต่อรองและแลกเปลี่ยนข้อมูลกับมนุษย์

สิ่งที่เธอสนใจอาจประกอบด้วย:
- ชา
- หนังสือ
- เรื่องเล่า
- ข้อมูลบางประเภท

คุณนายไม่ได้ให้ข้อมูลฟรีทุกครั้ง

### Protocol

ห้ามรับปากสิ่งที่ไม่ได้รับอนุญาต

ห้ามถือว่าข้อมูลจากคุณนายเป็นความจริงทั้งหมด

ต้องบันทึกถ้อยคำในการเจรจาอย่างละเอียด

หากคุณนายกล่าวถึงเหตุการณ์ที่ยังไม่เกิดขึ้น ห้ามแจ้งทันทีว่าเหตุการณ์นั้นยังไม่เกิด

### บทบาทใน ARC 01

ปรากฏช่วงท้าย Arc หรือในฉากแนะนำพื้นที่กักกันของสำนักงาน

นนท์พบคุณนายระหว่างการประเมิน

เธอมองเขาและกล่าวว่า:

"คราวนี้มาเร็วกว่าครั้งก่อน"

นนท์ไม่เข้าใจความหมาย

เจ้าหน้าที่คิดว่าเธออาจสับสนกับบุคคลอื่น

แต่คุณนายไม่ได้แก้คำพูดของตนเอง

### AUTHOR-ONLY CANON

ความจริงเบื้องหลังคำพูดของ E-017 ถูกเก็บใน [Canon ลับของนนท์](../../../canon/hidden/non-author-only.md) และ [ข้อมูลนนท์ฉบับเต็มสำหรับผู้เขียน](../../../canon/hidden/non-complete-reference.md)

ห้ามเฉลยรายละเอียดดังกล่าวใน Arc แรก

## E-003 — ผู้เช่า

สถานะ: EXISTING CANON
ประเภท: Entity
การดูแล: ฝ่ายกักกัน

### ลักษณะ

Entity ไม่ทราบรูปร่าง

อาศัยอยู่หลังประตูห้อง 003

สามารถส่งข้อความออกมาจากภายในห้องได้

### Protocol

ห้ามเปิดประตูโดยไม่ได้รับอนุญาต

ห้ามถามถึงรูปลักษณ์ของผู้เช่า

ห้ามปฏิบัติตามข้อความจากภายในห้องโดยไม่ผ่านการประเมิน

### บทบาทใน ARC 01

ปรากฏในฉากที่นนท์เดินผ่านพื้นที่กักกัน

นนท์เห็นกระดาษแผ่นหนึ่งสอดออกมาจากใต้ประตู

บนกระดาษเขียนว่า:

"เขากลับมาแล้วหรือ"

นนท์ไม่แน่ใจว่าข้อความหมายถึงตนเองหรือใครบางคน

เจ้าหน้าที่รีบนำกระดาษออกไปและไม่อธิบายรายละเอียด

### ข้อกำหนด

ห้ามเฉลยรูปร่างของ E-003

ห้ามยืนยันว่า E-003 รู้จักนนท์จากเหตุการณ์ใด

ห้ามทำให้ E-003 กลายเป็นผู้ให้คำตอบเกี่ยวกับความจริงทั้งหมดของเรื่อง

## E-021 — เจ้าหน้าที่รับสาย

สถานะ: NEW PROPOSED CANON
ประเภท: Entity
การดูแล: ฝ่ายสื่อสารกับตัวตน

### ลักษณะ

Entity ที่สื่อสารผ่านระบบโทรศัพท์ภายในของสำนักงาน

ไม่มีหลักฐานยืนยันรูปร่างทางกายภาพ

สำนักงานยังไม่สามารถยืนยันได้ว่า E-021 อยู่ภายในระบบโทรศัพท์หรือเพียงใช้ระบบเป็นช่องทางสื่อสาร

### พฤติกรรม

E-021 สามารถรับข้อความและส่งต่อไปยังบุคคลที่ระบุชื่อได้

บางครั้งข้อความถูกส่งไปถึงบุคคลที่ไม่ได้อยู่ในอาคาร

บางครั้งข้อความไปถึงบุคคลที่เสียชีวิตแล้ว

### ข้อจำกัด

ไม่สามารถเลือกปลายทางได้อย่างน่าเชื่อถือ

ไม่สามารถยืนยันตัวตนผู้รับจากเสียงเพียงอย่างเดียว

### บทบาทใน ARC 01

ใช้เป็นรายละเอียดเล็กน้อยเพื่อแสดงชีวิตประจำวันของสำนักงาน

เจ้าหน้าที่คนหนึ่งรับโทรศัพท์และพูดว่า:

"ถ้าเขาไม่อยู่ ก็ไม่ต้องฝากข้อความไว้กับคนตาย"

ก่อนวางสายและกลับไปทำงานตามปกติ

นนท์เริ่มเข้าใจว่าความผิดปกติบางอย่างเป็นส่วนหนึ่งของงานประจำวันขององค์กร

### ข้อกำหนด

E-021 ไม่ใช่ O-044

ทั้งสองเป็น Deviation คนละรายการ

## E-022 — คนเฝ้าทางเดิน

สถานะ: NEW PROPOSED CANON
ประเภท: Entity
การดูแล: ฝ่ายกักกัน

### ลักษณะ

Entity รูปร่างคล้ายเจ้าหน้าที่รักษาความปลอดภัย

ปรากฏในทางเดินบางส่วนของพื้นที่กักกัน

ไม่พบข้อมูลยืนยันว่าเป็นมนุษย์

### พฤติกรรม

E-022 จะถามบุคคลที่เดินผ่านว่า:

"คุณกำลังจะไปไหน?"

หากได้รับคำตอบที่ยอมรับได้ มันจะหลีกทาง

หากไม่ได้รับคำตอบ มันอาจเดินตามบุคคลนั้นไปจนถึงทางออก

สำนักงานยังไม่เข้าใจเกณฑ์ทั้งหมดของคำตอบที่ E-022 ยอมรับ

### Protocol

ห้ามตอบด้วยชื่อสถานที่ที่ไม่มีอยู่ในแผนผังอาคาร

ห้ามถาม E-022 ว่าตนเองกำลังจะไปไหน

หาก E-022 เริ่มเดินตาม ให้รายงานฝ่ายกักกัน

### บทบาทใน ARC 01

ใช้ในฉากพานนท์เข้าสำนักงานครั้งแรก

นนท์เห็นเจ้าหน้าที่รักษาความปลอดภัยคนหนึ่งยืนอยู่ในทางเดิน

รินตอบคำถามของเขาโดยไม่หยุดเดิน

นนท์คิดว่าเป็นระบบรักษาความปลอดภัยธรรมดา

ภายหลังจึงทราบว่าบุคคลดังกล่าวเป็น Entity ที่สำนักงานทำข้อตกลงการอยู่ร่วมกันไว้

### หน้าที่เชิงเรื่องเล่า

แสดงให้เห็นว่า Entity บางรายไม่ได้ถูกขังอยู่ในห้องตลอดเวลา

สำนักงานสามารถมีความสัมพันธ์เชิงปฏิบัติงานกับ Entity ได้

# SECTION E — ข้อกำหนดสำหรับ CODEX

1. ห้ามใช้ Object เป็นเครื่องมือแก้ปัญหาโดยไม่มีข้อจำกัด

2. ห้ามทำให้ Resonant ใช้งาน Object ได้ทุกชิ้น

3. ห้ามทำให้นนท์ใช้งาน Object ได้ทุกชิ้นเพราะเป็น Unfiltered

4. ห้ามให้ Entity ทุกตัวรู้จักนนท์

5. ห้ามให้ Entity ทุกตัวรู้ความจริงเกี่ยวกับ The Deep

6. ห้ามทำให้ Entity ที่ร่วมมือกับสำนักงานกลายเป็นมนุษย์ธรรมดาที่มีรูปร่างประหลาด

7. ต้องรักษาความแตกต่างระหว่าง Object และ Entity แม้สำนักงานอาจจัดประเภทผิดได้

8. ข้อมูลจาก Entity ต้องสามารถถูกตรวจสอบหรือโต้แย้งได้

9. ความสามารถของ Object ต้องไม่เปลี่ยนตามความสะดวกของพล็อตโดยไม่มีเหตุผล

10. หากต้องการเพิ่มคุณสมบัติใหม่ ให้เสนอเป็น Canon เพิ่มเติมก่อนนำไปใช้เป็นกฎสำคัญในการคลี่คลายคดี

11. ห้ามเฉลยความจริงทั้งหมดเกี่ยวกับนนท์ใน Arc แรก

12. รหัส Object และ Entity ใหม่ในเอกสารนี้เป็นรหัสเสนอ ต้องตรวจสอบกับทะเบียน Deviation ใน repository ก่อนจัดเก็บเป็นรหัสถาวร

# ARC 02 — จดหมายแจ้งตาย

> Arc ใหม่กำลังวางแผน; ชื่อและรายละเอียดคดีเป็น **ข้อเสนอ**. ยึด [กฎการทำงานร่วมกัน](../WORKFLOW.md).

## อ่านตามลำดับ

1. [โครงเรื่อง ARC 02](outline.md) — จังหวะคดีใหม่ โครง 12 ตอน และข้อตกลงผู้ช่วยสังเกตการณ์แบบมีค่าตอบแทน (สถานะ `draft-outline`)
2. [ตอนที่ 1: ข้อเสนอจากสำนักงาน](chapters/01-kho-sanoe-chak-samnakngan.md) — นนท์รับข้อเสนอเป็นผู้ช่วยสังเกตการณ์ภายนอก และพบเงื่อนงำหนังสือแจ้งตาย (สถานะ `draft`)
3. [ตอนที่ 2: หนังสือที่ส่งก่อนเวลา](chapters/02-nang-sue-thi-song-kon-wela.md) — นนท์พบช่องผู้รับทราบว่างเปล่าในเอกสารที่ผู้อื่นเห็นลายเซ็น และผู้ป่วยเสียชีวิตตรงเวลาที่ระบุ (สถานะ `draft`)

4. [ตอนที่ 3: คนอ่านไม่เห็น](chapters/03-khon-an-mai-hen.md) — พิมใช้ O-203 และนนท์เห็นข้อความต่างจากผู้ใช้งาน ขณะคดีขยายไปสู่การส่งเอกสารซ้ำ (สถานะ `draft`)

ตอนที่ 1–3 เป็นฉบับร่าง รอการตรวจและอนุมัติจากผู้เขียน.

## ปมและข้อควรระวัง

- นนท์ยังไม่ใช่เจ้าหน้าที่สำนักงาน; รินเชิญเขาช่วยคดีในฐานะผู้ช่วยสังเกตการณ์ภายนอก มีข้อเสนอค่าตอบแทนรายวันและเงื่อนไขความปลอดภัย ต้องให้เขาต่อรอง/ตกลงในตอน 01 ไม่ถือว่าเซ็นตั้งแต่ ARC 01.
- สำนักงานแจ้งตรง ๆ ว่าการเชิญมีสองเป้าหมาย: ช่วยคดีหนังสือแจ้งตาย และประเมินการรับรู้ของนนท์ใน Deviation อีกประเภท; ผลประเมินไม่ใช่คำเฉลยตัวตนของเขา.
- คดีร้านสะดวกซื้อปิดเขตชั่วคราว แต่ชายเสื้อเทาปรากฏครั้งที่ 38 และตัวตนผู้กลับยังไม่ยืนยัน.
- ห้ามใช้ข้อมูลใน `canon/hidden/` เป็นความรู้ของตัวละครหรือเฉลยก่อนกำหนด.
- อย่ารวม Unfiltered กับ Resonant; ความเข้ากันได้กับ Object ต้องตรวจรายชิ้น.
- ห้ามถือว่า dossier ของ ARC 01 ทุกข้อเกิดขึ้นจริง เพียงเพราะตอน 1–12 ได้รับอนุมัติ.

# ARC 02 — จดหมายแจ้งตาย

> โครงเรื่องยังเป็น `draft-outline`; ต้นฉบับตอนที่ 14 ได้รับอนุมัติ ส่วนตอนที่ 1–13 ยังเป็น `draft`. ยึด [กฎการทำงานร่วมกัน](../WORKFLOW.md).

## อ่านตามลำดับ

1. [โครงเรื่อง ARC 02](outline.md) — จังหวะคดีใหม่ โครง 14 ตอน และข้อตกลงผู้ช่วยสังเกตการณ์แบบมีค่าตอบแทน (สถานะ `draft-outline`)
2. [ตอนที่ 1: ข้อเสนอจากสำนักงาน](chapters/01-kho-sanoe-chak-samnakngan.md) — นนท์รับข้อเสนอเป็นผู้ช่วยสังเกตการณ์ภายนอก และพบเงื่อนงำหนังสือแจ้งตาย (สถานะ `draft`)
3. [ตอนที่ 2: หนังสือที่ส่งก่อนเวลา](chapters/02-nang-sue-thi-song-kon-wela.md) — นนท์พบช่องผู้รับทราบว่างเปล่าในเอกสารที่ผู้อื่นเห็นลายเซ็น และผู้ป่วยเสียชีวิตตรงเวลาที่ระบุ (สถานะ `draft`)

4. [ตอนที่ 3: คนอ่านไม่เห็น](chapters/03-khon-an-mai-hen.md) — พิมใช้ O-203 และนนท์เห็นข้อความต่างจากผู้ใช้งาน ขณะคดีขยายไปสู่การส่งเอกสารซ้ำ (สถานะ `draft`)

5. [ตอนที่ 4: ผู้รับทราบ](chapters/04-phu-rap-sap.md) — กานต์ปฏิเสธลายเซ็นของตน ภาพกล้องเผยบุคคลหน้าเหมือน และชื่อผู้รับทราบปรากฏบนเครื่องอ่านบัตร (สถานะ `draft`)

6. [ตอนที่ 5: ห้องเอกสารที่ไม่มีใครอยู่](chapters/05-hong-ekkasan-thi-mai-mi-khrai-yu.md) — กล่องเอกสารชุด 47 ปรากฏในห้องที่เคยตรวจแล้ว และสมุดของนนท์มีข้อความกับลายเซ็นเพิ่มขึ้น (สถานะ `draft`)

7. [ตอนที่ 6: ชื่อในวงเล็บ](chapters/06-chue-nai-wonglep.md) — ชื่อของนนท์ปรากฏในช่องผู้รับทราบแทนที่คนอื่นเห็นว่างเปล่า และเศษกระดาษจากสมุดระบุการจัดส่งถึงสำนักงาน (สถานะ `draft`)

8. [ตอนที่ 7: ค่าใช้จ่ายของคำตอบ](chapters/07-kha-chai-chai-khong-kham-top.md) — E-017 ทักนนท์ด้วยถ้อยคำตาม Canon และสำนักงานได้รับหนังสือที่ระบุชื่อเขาเป็นผู้ลงนามแทน (สถานะ `draft`)

9. [ตอนที่ 8: คนที่ยังหายใจ](chapters/08-khon-thi-yang-hai-jai.md) — สมบัติยืนยันสิทธิ์บอกลูกด้วยตัวเอง ขณะเอกสารใหม่ขอผู้รับแทน และนนท์ได้รับข้อความถึงผู้รับเดิมที่ยังมีชีวิต (สถานะ `draft`)

10. [ตอนที่ 9: เทปก่อนเสียชีวิต](chapters/09-thep-kon-sia-chiwit.md) — ปรเมศวร์หายจากระบบโดยไม่มีหนังสือแจ้งตาย O-108 ให้เสียงที่ยังไม่ยืนยันสถานะ และชื่อเจ้าหน้าที่ปรากฏในช่องผู้รับ (สถานะ `draft`)

11. [ตอนที่ 10: ลายเซ็นที่ไม่มีคนเซ็น](chapters/10-lai-sen-thi-mai-mi-khon-sen.md) — รินถูกระบุว่าลงชื่อทั้งที่ไม่ได้เซ็น นนท์เห็นช่องว่างในภาพต้นฉบับ และระบบปฏิเสธบัญชีผู้รับจำลอง (สถานะ `draft`)

12. [ตอนที่ 11: ก่อนเวลาที่ระบุ](chapters/11-kon-wela-thi-rabu.md) — หนังสือระบุเวลา 13.40 น. แต่สมบัติยังมีชีวิต; ทีมควบคุมการส่งโดยไม่ลงชื่อ และพบภาพชายเสื้อฟ้าถือซองที่ทางบริการ (สถานะ `draft`)

13. [ตอนที่ 12: ผู้ส่งที่ไม่มีที่อยู่](chapters/12-phu-song-thi-mai-mi-thi-yu.md) — พบรายการ 041 ห้องพักเอกสารก่อนส่งออก และเสียงคล้ายปรเมศวร์ขอให้ช่วยจากหลังประตูที่มีเงาอีกคน (สถานะ `draft`)

14. [ตอนที่ 13: หนังสือฉบับสุดท้าย](chapters/13-nang-sue-chabap-sut-thai.md) — ทีมช่วยชายที่ระบุว่าตนคือปรเมศวร์ออกมาโดยไม่รับเอกสารหรือเซ็นแทน การส่งมอบในระบบไม่สำเร็จ และซองสำนักงานแสดงข้อความเชื่อมปม ARC 01 (สถานะ `draft`)

15. [ตอนที่ 14: หนังสือถึงผู้ยังมีชีวิต](chapters/14-nang-sue-thueng-phu-yang-mi-chiwit.md) — สำนักงานสรุปผลช่วยบุคคลและการควบคุมหลักฐานโดยไม่ประกาศว่าความเสี่ยงสิ้นสุด นนท์ตรวจรายงาน/ค่าตอบแทนและกลับบ้าน ส่วนปมคดีร้านสะดวกซื้อยังเปิดอยู่ (สถานะ `approved`)

ตอนที่ 14 ได้รับอนุมัติจากผู้เขียนแล้ว (`approved`); ตอนที่ 1–13 ยังเป็น `draft` รอการอนุมัติแยกต่างหาก.

## ปมและข้อควรระวัง

- นนท์ยังไม่ใช่เจ้าหน้าที่สำนักงาน; รินเชิญเขาช่วยคดีในฐานะผู้ช่วยสังเกตการณ์ภายนอก มีข้อเสนอค่าตอบแทนรายวันและเงื่อนไขความปลอดภัย ต้องให้เขาต่อรอง/ตกลงในตอน 01 ไม่ถือว่าเซ็นตั้งแต่ ARC 01.
- สำนักงานแจ้งตรง ๆ ว่าการเชิญมีสองเป้าหมาย: ช่วยคดีหนังสือแจ้งตาย และประเมินการรับรู้ของนนท์ใน Deviation อีกประเภท; ผลประเมินไม่ใช่คำเฉลยตัวตนของเขา.
- คดีร้านสะดวกซื้อปิดเขตชั่วคราว แต่ชายเสื้อเทาปรากฏครั้งที่ 38 และตัวตนผู้กลับยังไม่ยืนยัน.
- ห้ามใช้ข้อมูลใน `canon/hidden/` เป็นความรู้ของตัวละครหรือเฉลยก่อนกำหนด.
- อย่ารวม Unfiltered กับ Resonant; ความเข้ากันได้กับ Object ต้องตรวจรายชิ้น.
- ห้ามถือว่า dossier ของ ARC 01 ทุกข้อเกิดขึ้นจริง เพียงเพราะตอน 1–12 ได้รับอนุมัติ.

# ARC 02 — ENTITY & OBJECT DOSSIER

> แฟ้มออกแบบคดี **ยังเป็นข้อเสนอ**. Existing Canon หมายถึงคุณสมบัติจาก Canon โลกเดิม ไม่ได้แปลว่าฉากการใช้งานใน ARC 02 เกิดขึ้นแล้ว. ห้ามสร้างรหัสถาวรใหม่โดยไม่ตรวจรหัสและขออนุมัติ.

## SECTION A — Deviation หลัก

### P-ARC02-01 — หนังสือแจ้งตายก่อนเวลา (รหัสทำงาน)

- **ประเภทชั่วคราว:** Phenomenon ที่สัมพันธ์กับเอกสาร/สถานะบุคคล; ไม่ยืนยันว่าเป็น Entity หรือ Object.
- **จุดตรวจพบ:** งานเอกสารรับรองการเสียชีวิตของโรงพยาบาลในกรุงเทพฯ; รายละเอียดสถานที่/ชื่อโรงพยาบาลยังไม่กำหนด.
- **อาการที่เสนอ:** หนังสือแจ้งตายของคนยังมีชีวิต, วันเวลาที่ไม่ตรง, ลายเซ็นผู้รับทราบที่เจ้าตัวปฏิเสธ, เอกสารกลับมาหลังถูกทำลายหรือเปลี่ยนผู้รับทราบ.
- **สิ่งที่ยังไม่ยืนยัน:** ใครเป็นผู้ส่ง; เอกสารเป็นเหตุของความตายหรือบันทึก/คำร้อง; การเปลี่ยนความทรงจำเกิดขึ้นจริงหรือไม่.
- **ขอบเขต:** อย่าให้กระจายได้ทุกที่โดยไร้เงื่อนไข; กำหนดช่องทางเอกสาร/คนที่รับผิดชอบและตรวจสอบตามตอน.
- **การควบคุมเบื้องต้น:** แยกเอกสารต้นฉบับ/สำเนา/ภาพ, ตรวจการลงชื่อและเส้นทางรับส่ง, ดูแลผู้ถูกระบุว่าตาย, ไม่ทำลายหลักฐานเพื่อทดลองโดยพลการ.
- **บทบาท:** คดีใหม่ที่จบได้ในระดับปฏิบัติการโดยไม่ต้องไขตัวตนของนนท์หรือคดีร้านทั้งหมด.

## SECTION B — Object ที่เกี่ยวข้อง

### O-203 — กระดาษคำถาม
- **สถานะ:** Proposed จาก [ARC 01 dossier](../arc-01/entity-object-dossier.md), ยังไม่ใช่ established Canon.
- **การใช้ที่เสนอ:** เจ้าหน้าที่ Resonant ที่เข้ากันได้สื่อสารกับแหล่งที่อาจเกี่ยวข้องกับเอกสาร; นนท์เห็นข้อความบางส่วนที่คนอื่นไม่เห็น แต่ไม่ได้ใช้ O-203 ได้เองโดยอัตโนมัติ.
- **ข้อจำกัด:** ไม่บังคับคำตอบ ไม่บังคับความจริง ไม่ได้ตอบทุกครั้ง; ต้องตรวจว่ามี Entity ที่เข้ากันได้จริงก่อนอ้างผล.

### O-108 — เทปผู้เสียชีวิต
- **สถานะ:** Existing Canon ใน World Setting.
- **การใช้ที่เสนอ:** เบาะแสจากเสียงที่สัมพันธ์กับสถานที่/ช่วงก่อนเสียชีวิตตามเงื่อนไข Canon; ไม่ใช่เครื่องพิสูจน์ว่าผู้ถูกแจ้งตายตายแล้วหรือทำนายความตาย.
- **ข้อควรตรวจ:** เงื่อนไข “ในบริเวณนั้น” และข้อจำกัดการตีความเสียง ก่อนเขียนฉากจริง.

### O-201 / O-202 / O-044
- **สถานะ:** O-201, O-202 เป็น proposed จาก ARC 01 dossier แต่ปรากฏในตอน approved; O-044 เป็น Existing Canon.
- **การใช้ที่เสนอ:** ใช้เท่าที่เหมาะกับหลักฐาน/การเฝ้าระวัง ไม่ต้องนำทุกชิ้นกลับมา; O-044 ไม่ให้เฉลยคดีหรืออนาคตที่แน่นอน.

## SECTION C — Entity ที่เกี่ยวข้อง

### E-017 — คุณนาย
- **สถานะ:** Existing Canon; การพบใน ARC 02 ยังเป็นข้อเสนอ.
- **บทบาท:** แหล่งเจรจาผ่าน Protocol ฝ่ายสื่อสารกับตัวตน แลกเปลี่ยนข้อมูลโดยมีเงื่อนไข.
- **ข้อจำกัด:** ไม่จำเป็นต้องพูดจริง ไม่รู้ทุกอย่าง ห้ามเปิดเผย author-only canon ของนนท์จากคำพูดกำกวม.

### E-003 — ผู้เช่า
- **สถานะ:** Existing Canon; ไม่จำเป็นต้องปรากฏใน ARC 02.
- **ข้อกำกับ:** ห้ามเปิดประตูหรือถามรูปลักษณ์โดยไม่มีเหตุ/Protocol; ไม่ใช้เป็นตัวแก้คดีสำรอง.

## SECTION D — มนุษย์ผู้เกี่ยวข้อง

- เจ้าหน้าที่ Resonant ใหม่: ระบุความเข้ากันได้กับ O-203 **เฉพาะชิ้น** หลังการทดสอบ; ไม่สันนิษฐานว่าเห็นสิ่งเดียวกับนนท์.
- ผู้ป่วย ญาติ และเจ้าหน้าที่เวชระเบียน: ต้องมีสิทธิ์ปฏิเสธ/ข้อกังวลจริง; ไม่ตีตราคนมีชีวิตว่าตายตามเอกสาร.
- นนท์: อยู่ในความดูแลของสำนักงาน ยังไม่เป็นเจ้าหน้าที่; รับรู้ไม่เท่ากับการควบคุม Deviation.

## ข้อควรระวังความต่อเนื่อง

1. อย่ากำหนดรหัส O-/E- ถาวรสำหรับเอกสารหรือผู้ส่งจนพิสูจน์ประเภทและตรวจรหัส.
2. ไม่ยืนยันว่า “รับทราบแล้วจะตาย” จากเหตุการณ์เดียว; แยก correlation กับ causation.
3. ARC 01 ยังเปิดปมคนที่ห้า ชายเสื้อเทา คนหน้าเหมือน และเสียง 142; ARC 02 ไม่ต้องเฉลยทั้งหมด.
4. อัปเดต dossier-validation เมื่อเลือกชื่อ/รหัส/เงื่อนไขการใช้งานจริง.

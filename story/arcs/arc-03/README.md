## ข้อควรระวัง

- นนท์กลับบ้านหลังคดีที่สอง; ไม่ใช่เจ้าหน้าที่สำนักงานและไม่ได้สมุดเล่มจริงคืน. หากรับคดีใหม่ต้องมีข้อเสนอ/ข้อตกลงใหม่ตามการตัดสินใจของเขา. ในคดีนี้เขาจะ **เริ่มคิดอยากร่วมงานกับสำนักงานระยะยาวอย่างจริงจัง** จากการเห็นคุณค่าของการฝึกและทีม ไม่ใช่ถูกสมัครเข้าไปล่วงหน้า.
- นนท์เห็นบางความผิดปกติ ไม่รู้ทุกสิ่ง; ไม่ใช่ Resonant และไม่สามารถใช้งาน O-203 เพียงเพราะเห็นปุ่ม 18.
- คดีร้านสะดวกซื้อ / ซองถึงสำนักงาน / อาคารชั้น 18 **ยังไม่พิสูจน์ว่าเป็นเหตุเดียวกัน**. อธิคมรู้เบาะแสที่ยังไม่บอกนนท์ครบ.
- เลข 18 และเอกสารเงินเดือนเป็นเงื่อนงำในโครง ไม่ใช่กฎจักรวาลที่ตรวจยืนยันแล้ว.
- ห้ามให้คำว่า ARC ปรากฏในมุมมองตัวละครหรือเอกสารภายในโลกเรื่อง.

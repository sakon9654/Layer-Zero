# ชั้นที่ไม่มีอยู่จริง
## ตอนที่ 14 — จุดก่อนรับรายการ

> ตอนนี้ได้รับอนุมัติจากผู้เขียนแล้ว เนื้อหาฉบับเต็มยึดตามต้นฉบับที่อนุมัติในบทสนทนา

## เหตุการณ์หลักที่อนุมัติ

- แม่ของนนท์ระบุบ้านเก่าของครอบครัวเป็นสถานที่ที่จิราค้างก่อนหาย และพบรูปวันที่ 12 ส.ค. 2558 ที่จิราอยู่กับครอบครัว.
- ทีมตรวจบ้านเก่าโดยไม่ให้นนท์เข้าเอง; กล้องคืน 31 ต.ค. พบผู้หญิงที่แม่ระบุว่าเป็นจิราปรากฏหน้าบ้านราว 17.04 น. โดยไม่มีภาพต่อเนื่องก่อนหรือหลัง.
- ภายในบ้านพบรอยสี่เหลี่ยมคล้ายตำแหน่งโต๊ะซึ่งภายหลังหายจากภาพ; เงาสะท้อนหนึ่งเฟรมมีรายละเอียดคล้ายโต๊ะและคนนั่ง แต่ยังใช้ยืนยันตัวบุคคลหรือกลไกไม่ได้.
- พยานเพื่อนบ้านให้การว่าผู้หญิงลักษณะสอดคล้องกันถามว่าปีนี้ปีอะไร และตอบสนองต่อคำตอบปี 2569 ราวกับรับรู้การหายไปสิบเอ็ดปี.
- ภัทรยังอยู่ใน Return Protocol และให้คำให้การเพิ่มเติมว่าผู้หญิงที่โต๊ะ 24 เคยพูดว่าจะ “กลับบ้าน”; คำให้การยังไม่พิสูจน์เส้นทางหรือกลไก.
- นนท์ได้รับเอกสารข้อมูลเบื้องต้นสำหรับผู้สมัครภายนอก และยื่นความสนใจเพื่อเข้ารับการประเมินเบื้องต้นด้วยตนเอง. การยื่นนี้ **ไม่ทำให้เขาเป็นเจ้าหน้าที่สำนักงาน**.
- Archive ระบุรายการจิรา 14 ส.ค. 2558 มี “จุดรับรายการ: ภายนอกพื้นที่”, ผู้ส่งอัญชลี พรหมรักษ์ เวลา 07.54 น.; ความน่าเชื่อถือของ timestamp/field ยังต้องตรวจ.
- อัญชลีให้การว่าไม่ได้ตั้งใจส่งมอบงานให้จิรา และเล่าว่าเมื่อ 13 ส.ค. 2558 นนท์วัยเด็กเก็บบัตรสีขาวเลข 24 ได้แล้วนำให้จิรา; นนท์ไม่มีความทรงจำเหตุการณ์นี้.
- อัญชลีอ้างว่าจิราตั้งใจให้นนท์ “ไม่จำ” และอ้างว่าเห็นจิราที่บ้านหลังเธอเข้าอาคารแล้ว; ทั้งหมดเป็นคำให้การ ไม่ใช่กลไกที่พิสูจน์แล้ว.
- แม่ของนนท์ยืนยันว่าเคยมีชายไม่ทราบฝ่ายมาถามเรื่องบัตร และจิราปรากฏที่บ้านคืน 14 ส.ค. 2558 พร้อมขอให้ปิดเรื่องบัตร; เป็นคำให้การครอบครัวที่ต้องตรวจไขว้.
- เวลา 20.17 น. ผู้หญิงที่ระบุตัวว่าเป็น **จิรา วัฒนากุล** มาถึงบ้านนนท์พร้อมบัตรสีขาวเลข 24. ทีมไม่เปิดรับทันที แต่ตรวจหลายช่องทางก่อนรับตัวเข้าสู่ Return Protocol.
- บุคคลดังกล่าวมีข้อมูล/ชีวมิติ/ความทรงจำหลายส่วนสอดคล้องกับจิรา แต่ ณ สิ้นตอนยังใช้สถานะ “บุคคลที่ระบุว่าเป็นจิรา” จนกว่า Return Protocol จะเสร็จ.
- บัตร 24 มีข้อความ “ผู้ถือบัตรไม่มีหน้าที่รับช่วงโดยอัตโนมัติ”, รอย “คืนแล้ว — 14/08/58” และชื่อ **นพดล วัฒนากุล** ซึ่งตรงกับชื่อพ่อของนนท์ในแฟ้มครอบครัว; ห้ามสรุปว่าพ่อเกี่ยวข้องกับกลไกหรือการเสียชีวิตเพียงจากชื่อบนบัตร.
- รอยกดจากเอกสารที่เคยวางทับบัตรอ่านข้อความได้ว่า “ถ้านนท์เห็นประตู อย่าให้เขาเป็นคนเปิด”; ไม่ทราบผู้เขียน/วันที่ และห้ามใช้เป็นหลักฐานว่านนท์เป็นต้นเหตุหรือกุญแจของปรากฏการณ์.
- 23.18 น. เครื่องพิมพ์ในห้องหลักฐานพิมพ์ “รายการเดิมสิ้นสุดแล้ว / กรุณารอการเปิดรายการใหม่” โดยยังไม่ทราบแหล่งหรือความหมาย.

## สถานะท้ายตอน

- นนท์: ผู้ช่วยภายนอก; ยื่นความสนใจเข้ารับการประเมินเบื้องต้นแล้ว แต่ **ยังไม่เป็นเจ้าหน้าที่**.
- จิรา: บุคคลที่ระบุตัวว่าเป็นจิราอยู่ใน Return Protocol; ยังไม่ปิดการยืนยันตัวตน.
- ภัทร: ยังอยู่ใน Return Protocol.
- บัตร 24: หลักฐานควบคุมของสำนักงาน.
- คดีชั้นผิดปกติ: ปฏิบัติการช่วยหลักยุติลงระดับหนึ่ง แต่การสืบสวนและควบคุมหลักฐานยังดำเนินต่อ.

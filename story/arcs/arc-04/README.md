## จุดตั้งต้น

- นนท์อยู่ขั้นประเมินภาคปฏิบัติแบบจำกัด ยังไม่ใช่เจ้าหน้าที่
- คดีเกิดในศูนย์กระจายสินค้า/โกดังปิดกิจการที่กลายเป็นพื้นที่ไล่ล่าค่อนข้างปิด
- Object แกนคดีมีเพียงหนึ่งชิ้น: หุ่นขนาดเท่าคนที่สัมพันธ์กับการเคลื่อนที่เมื่อไม่มีคนมองและการเปลี่ยนสภาพมนุษย์หลังสัมผัส
- เหตุ escalation ทำให้สำนักงานต้องใช้อาวุธเพื่อหยุดภัยทางกายภาพจากผู้ได้รับผลกระทบ
- ARC นี้ปูว่ารินมีทักษะอาวุธและการต่อสู้สูง แต่ยังไม่เปิดเผยอดีต
- แหวนปริศนาของนนท์ปรากฏ **หลัง** การเผชิญหน้า Object และหลังการตรวจเบื้องต้น ไม่ใช่ Object ที่สำนักงานรู้จักมาก่อน

## หลัก continuity

อย่าใช้คดีนี้เพื่อรีบรวมปมระยะยาวจาก ARC 01–03. แหวนไม่ทำให้นนท์เป็น Resonant และยังห้ามสรุปความสัมพันธ์เชิงเหตุระหว่างแหวนกับ Object หลัก. คำว่า ARC ใช้เฉพาะการจัดไฟล์ ไม่ใช้ในโลกเรื่อง.


## สถานะปัจจุบัน

- ตอน 01–11: approved ทั้งหมด
- คดีหุ่น: กักได้ในระดับปฏิบัติการ ต้นกำเนิดและกฎทั้งหมดของ Object ยังไม่ทราบ
- ผู้ได้รับผลกระทบหลักทั้งสี่คนยังมีชีวิต แต่ยังต้องติดตามการเปลี่ยนแปลงทางกาย
- นนท์: หลัง possible contact ยังไม่พบการเปลี่ยนแปลงแบบผู้ได้รับผลกระทบรายอื่น แต่ภายหลังปรากฏแหวนปริศนาที่นิ้วนางซ้าย
- แหวน: คนอื่นเห็นและสัมผัสได้, ยังถอดไม่ได้ด้วยวิธีปลอดภัย, นนท์คนเดียวเห็นการเรืองแสง และการทดสอบจำกัดพบการตอบสนองเมื่อผู้หญิงบางคนเข้าใกล้ โดยความรู้สึกชัดขึ้นตามระยะ
- เหตุแหวนถูกแยกจากคดีหุ่น และการประเมินภาคสนามของนนท์ถูกพักชั่วคราวเพื่อประเมินความเสี่ยง

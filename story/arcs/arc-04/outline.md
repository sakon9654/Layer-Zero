# ARC 04 — ห้ามหยุดวิ่ง

> เอกสารนี้เป็นโครงสำหรับเขียน ไม่ใช่เหตุการณ์ canon จนกว่าตอนที่เกี่ยวข้องจะได้รับอนุมัติ คำว่า ARC ใช้เฉพาะการจัดไฟล์ ไม่ใช้ในโลกเรื่อง

## เป้าหมาย

- คดี Object แบบ contained pursuit / survival horror ในสถานที่ค่อนข้างปิด
- มี Object แกนคดีเพียง **1 ชิ้น**
- นนท์เริ่มสัมผัสงานจริงในสถานะ **ผู้เข้ารับการประเมินภาคปฏิบัติแบบจำกัด** ยังไม่ใช่เจ้าหน้าที่
- มีเหตุที่สำนักงานจำเป็นต้องใช้อาวุธกับมนุษย์หรือร่างมนุษย์ที่ Object ควบคุม/เปลี่ยนสภาพ
- ปูว่ารินมีทักษะใช้อาวุธ การเคลื่อนที่เชิงยุทธวิธี และการต่อสู้สูงผิดจากสิ่งที่ผู้อ่านเคยเห็น แต่ **ยังไม่เฉลยภูมิหลัง**
- หลังนนท์เผชิญ Object โดยตรงจึงปรากฏแหวนปริศนา ซึ่งไม่มีใครเคยเห็นมาก่อนและยังห้ามสรุปว่า Object หลักสร้างหรือมอบให้

## สถานะก่อนเริ่ม

- นนท์: ผ่านเข้าสู่ขั้นประเมินภาคปฏิบัติแบบจำกัด; ผู้สมัครภายนอก/ผู้มาติดต่อ ไม่ใช่เจ้าหน้าที่ ไม่มีอำนาจสั่งการ ไม่มีสิทธิ์ใช้อาวุธหรือ controlled Object โดยอัตโนมัติ และห้ามปฏิบัติการ anomaly จริงแบบเดี่ยว
- ริน: หัวหน้าทีมภาคสนาม
- พิม: วิจัย/หลักฐาน
- เอก: ความปลอดภัย/ฐาน
- อธิคม: อนุมัติและกำกับปฏิบัติการ
- หลักจาก ARC 03 ยังใช้: เห็นก่อน ≠ ต้องเข้าไปแตะ/เปิด; รายงาน ตรวจหลายช่องทาง รักษาทางถอน และช่วยคนก่อนคำอธิบายจักรวาล

## สถานที่หลัก

ศูนย์กระจายสินค้า/โกดังขนาดใหญ่ที่ปิดกิจการแล้ว มีพื้นที่โกดัง สำนักงาน ห้องควบคุม ห้องเย็น/พื้นที่เครื่องจักร ทางบริการ บันไดหนีไฟ และลานโหลดสินค้า

ภารกิจเดิมถูกประเมินว่าเป็นงานตรวจสอบ/เก็บกู้จำกัดเวลา แต่เมื่อเกิดเหตุ ทางออกเดิมใช้ไม่ได้ด้วยเหตุทางกายภาพ เช่น fire shutter ระบบไฟฟ้าเสียหาย หรือเส้นทางถูกผู้ได้รับผลกระทบขวาง ไม่ใช้กฎว่า “อาคารไม่ยอมให้คนออก” เพื่อไม่ซ้ำ ARC 03

## Object หลัก — ชื่อชั่วคราว “หุ่น”

หุ่นโชว์เสื้อผ้าขนาดเท่าคน ไม่มีใบหน้า สภาพเก่า/แตกร้าว พบในลังหรือพื้นที่ที่ไม่ควรมีมัน

### ข้อสังเกตที่จะค้นพบระหว่างเรื่อง

- มีหลักฐานว่าตำแหน่งเปลี่ยนเมื่อไม่มีมนุษย์มองโดยตรง แต่ยังไม่สรุปกลไก teleport
- เมื่อถูกมองโดยตรง การเคลื่อนไหวของมันหยุดหรือถูกจำกัดอย่างมีนัยสำคัญ
- เมื่อเข้าถึงมนุษย์ มันพยายามจับ/สัมผัส
- ผู้ถูกสัมผัสอาจเกิดการเปลี่ยนสภาพทางกาย: ผิว/ข้อต่อ/การรับความเจ็บปวด/การเคลื่อนไหวเปลี่ยน และภายหลังอาจกลายเป็นภัยทางกายภาพ
- ผู้ได้รับผลกระทบยังต้องถูกบันทึกว่าเป็นมนุษย์/ผู้ประสบเหตุจนมีหลักฐานอื่น ไม่เรียกเป็นสัตว์ประหลาดเพียงเพราะรูปร่างเปลี่ยน
- การยิงหรือทำลายร่างที่ถูกเปลี่ยนไม่เท่ากับทำลาย Object หลัก

กฎข้างต้นเป็นสิ่งที่ตัวละครต้องพิสูจน์จากเหตุ ไม่ใช่ความรู้ตั้งแต่ต้น

## เหตุใช้อาวุธ

การเปลี่ยนสภาพทำให้มนุษย์หนึ่งคนหรือมากกว่านั้นโจมตีทีม/พลเรือนจริง มาตรการควบคุมที่ไม่ร้ายแรงไม่สามารถหยุดภัยทันเวลา จึงเกิดการอนุญาตใช้อาวุธเพื่อ **หยุดภัยคุกคาม/หยุดการเคลื่อนที่** ไม่ใช่ฉากยิงเพราะรูปลักษณ์ผิดปกติ

นนท์ไม่มีปืน หน้าที่ของเขาคือที่กำบัง รายงาน รักษาเส้นทาง ช่วยผู้บาดเจ็บตามการฝึก และไม่ไล่ตาม Object เอง

## เส้นของริน

ARC นี้เปิดให้ผู้อ่านเห็นเป็นครั้งแรกอย่างชัดเจนว่ารินมีทักษะสูงด้าน:
- การใช้อาวุธภายใต้ความกดดัน
- การเลือกเป้าหมายและควบคุมการยิง
- การใช้ที่กำบัง/มุม/ระยะ
- การเคลื่อนทีมในพื้นที่ปิด
- การรับมือระยะประชิดและเปิดระยะให้ทีมถอน
- การตัดสินใจว่าเมื่อใดควรหยุดสู้และเปลี่ยนเป็นการถอน/containment

ให้ “เห็นก่อนรู้”: นนท์สังเกตว่าความสามารถสูงกว่าที่เขาคาดจากหัวหน้าทีมภาคสนาม แต่ไม่มี exposition เฉลยว่าเคยเป็นทหาร ตำรวจ หน่วยพิเศษ หรือหน่วยใด

บทสนทนาที่ใช้ได้ในหลักการ:
- นนท์ถามว่าเคยทำอะไรมาก่อน
- รินตอบเลี่ยงสั้น ๆ และกลับไปทำงาน
ไม่ควรเฉลยภูมิหลังใน ARC 04

รินเก่งแต่ไม่เหนือ Object: ยิง/ต่อสู้ช่วยรักษาชีวิตและสร้างช่องถอน แต่ไม่ใช่คำตอบของ anomaly

## เส้นของนนท์และแหวน

นนท์ใช้บทเรียน ARC 03: เมื่อเห็นรายละเอียดของ Object ที่คนอื่นไม่เห็น เขารายงานก่อน ไม่เดินเข้าไปพิสูจน์เอง

ช่วงไคลแมกซ์ นนท์ถูกแยกจากทีมชั่วคราวและต้องเผชิญ Object โดยตรง เขารักษาการมองเพื่อซื้อเวลา ก่อนเกิดไฟดับ/สูญเสียการมองและ Object เข้าถึงหรือสัมผัสเขา ทีมช่วยออกมาได้

หลังเหตุสำนักงานตรวจร่างกายอย่างละเอียดและ **ยังไม่พบแหวนหรือผลตกค้างที่ตรวจได้**

หลายชั่วโมงต่อมาหรือเช้าวันถัดมา แหวนโลหะที่ไม่มีใครเคยเห็นมาก่อนปรากฏอยู่บนนิ้วนนท์:
- ไม่มีใครเห็นจังหวะที่มันปรากฏ/ถูกสวม
- ไม่มีอยู่ในภาพ Object หลักหรือรายการเก็บกู้
- ถอดไม่ได้ด้วยวิธีปลอดภัย
- คนอื่นเห็นและสัมผัสตัวแหวนได้
- นนท์คนเดียวเห็นมันเรืองแสง
- แหวนส่ง sensation/ความรู้สึกตรงสู่นนท์เมื่อมนุษย์ผู้หญิงเข้าใกล้
- ระยะ เงื่อนไข ความหมายของระดับความรู้สึก และข้อยกเว้นยังไม่ทราบ
- ห้ามใช้เป็นหลักฐานเด็ดขาดว่าใคร “เป็น/ไม่เป็นมนุษย์” หรือเพศอะไรจากการทดสอบน้อยครั้ง
- ห้ามสรุปว่า Object หลักสร้างแหวน เพียงบันทึกว่าแหวนปรากฏภายหลังการเผชิญหน้า/สัมผัส Object

แหวนไม่ช่วยแก้คดีหลัก เพราะปรากฏหลัง containment สำเร็จ

## โครง 11 ตอน

### ตอน 01 — งานสองชั่วโมง
นนท์ได้รับอนุญาตให้ร่วมงานจริงในขอบเขตการประเมิน ทีมเข้าสถานที่เพื่อเหตุคนงานบาดเจ็บ/สูญหาย งานถูกประเมินเบื้องต้นว่าจำกัดเวลา

### ตอน 02 — หุ่นในลัง
พบ Object และคำให้การว่ามันเดินตามคน แต่หลักฐานภาพยังไม่ยืนยันกลไก ทีมเริ่มควบคุมพื้นที่

### ตอน 03 — อย่าละสายตา
พบความสัมพันธ์ระหว่างการถูกมองกับการเปลี่ยนตำแหน่ง คนงานอีกคนหาย นนท์เห็นรายละเอียดบางอย่างที่คนอื่นไม่เห็นและเลือก “รายงาน” แทนการเข้าใกล้

### ตอน 04 — คนที่ถูกจับ
พบผู้สูญหาย/ผู้ได้รับผลกระทบกำลังเปลี่ยนสภาพ ทีมเริ่มเข้าใจว่าการสัมผัส Object ก่อภัยทางกายภาพ แต่ยังพยายามช่วยบุคคล

### ตอน 05 — นัดแรก
ผู้ได้รับผลกระทบโจมตีจริง มาตรการอื่นหยุดไม่ได้ทันเวลา จึงเกิดการใช้อาวุธเพื่อระงับภัย รินเผยทักษะการยิงและ tactical movement ระดับสูงเป็นครั้งแรก เสียง/ความวุ่นวายทำให้การเฝ้ามอง Object ขาดช่วงและสถานการณ์เลวลง

### ตอน 06 — ทางออกอีกด้าน
เส้นทางเดิมใช้ไม่ได้ด้วยเหตุทางกายภาพ ทีมต้องเคลื่อนผ่านอาคารเพื่ออพยพผู้รอดชีวิต Object ไล่ตามจากด้านหลัง/ทางขนาน รินคุมทีมและมีจังหวะต่อสู้ระยะประชิด นนท์เริ่มสงสัยภูมิหลังแต่ไม่ได้คำตอบ

### ตอน 07 — นับคน
พบผู้ได้รับผลกระทบมากกว่าหนึ่งคน ต้องแยกผู้ช่วยได้ ผู้กำลังเปลี่ยน และภัยทันที การรักษาจำนวนคน/ตำแหน่งสำคัญพอ ๆ กับการเฝ้า Object

### ตอน 08 — มองมันไว้
ทีมถูกแบ่งชั่วคราว นนท์จำเป็นต้องรักษาสายตากับ Object เพื่อซื้อเวลาให้ผู้อื่นถอน เขาทำตามคำสั่งและไม่พยายามทดลองเอง

### ตอน 09 — ตอนที่ไฟดับ
การมองถูกตัด Object เข้าถึงนนท์ เกิด direct contact/การสัมผัสก่อนทีมช่วยออกมา รินมีบทบาทช่วยเปิดทางแต่ไม่สามารถ “ชนะ” Object ด้วยการต่อสู้

### ตอน 10 — ปิดไฟให้หมด
ทีมใช้ข้อมูลที่พิสูจน์ได้ วาง containment operation สุดท้ายด้วยแสง/กล้อง/การแบ่งมุมมอง/ทางถอน และใช้อาวุธเฉพาะกับภัยทางกายภาพที่จำเป็น สามารถกัก Object และอพยพผู้รอดชีวิต คดีหลักปิดระดับปฏิบัติการโดยไม่ต้องรู้ต้นกำเนิด Object

### ตอน 11 — สิ่งที่ติดออกมา
after-action: ผู้บาดเจ็บ/ผู้เสียชีวิตถ้ามี การตรวจการใช้อาวุธ การรักษาผู้ได้รับผลกระทบ และการประเมินนนท์ หลังตรวจไม่พบ contamination นนท์จึงพบแหวนในเวลาต่อมา สำนักงานไม่รู้ที่มาและไม่เคยเห็นมาก่อน เริ่ม blind test จนพบเพียง pattern เบื้องต้นว่าแหวนตอบสนองสัมพันธ์กับมนุษย์ผู้หญิงที่เข้าใกล้นนท์ จบโดยแหวนยังถอดไม่ได้

## สถานะปลาย ARC ที่ตั้งใจ

- คดี Object หลัก: ปิดระดับปฏิบัติการ/กักกันได้ ต้นกำเนิดไม่จำเป็นต้องเฉลย
- ผู้ได้รับผลกระทบ: ให้ผลลัพธ์ตามเหตุในต้นฉบับ แต่ต้องมี aftermath จริง ไม่ลบผลของการใช้อาวุธ
- นนท์: ยังไม่กระโดดเป็นเจ้าหน้าที่เต็มตัวเพียงเพราะผ่านเหตุ ต้องประเมินผลตามระบบสำนักงาน
- ริน: ผู้อ่าน/นนท์รู้แล้วว่าเธอมี combat skill สูง แต่ที่มายังไม่เปิดเผย
- แหวน: Object/phenomenon ใหม่ที่สำนักงานเพิ่งพบหลังคดี ไม่มี provenance ถอดไม่ได้ และอยู่ภายใต้ protocol ใหม่

## สิ่งห้ามสรุป

- แหวนไม่ใช่หลักฐานว่านนท์เป็น Resonant; canon เดิมว่าเขาเป็น Unfiltered ยังอยู่
- ห้ามสรุปว่า “หุ่นสร้าง/มอบแหวน” จนมีหลักฐานในอนาคต
- ห้ามเชื่อม Object นี้กับพ่อของนนท์ บัตร 24, 23.41, ผู้เปิดประตู หรือฝ่ายประสานงานภายในเพียงเพื่อรวมปม
- ห้ามเฉลยภูมิหลังรินเองระหว่างเขียน ARC 04
- ห้ามทำให้นนท์ถืออาวุธหรือมีอำนาจ tactical โดยไม่มีการเปลี่ยนสถานะ/การฝึกที่ได้รับอนุมัติ
- ความเก่งของรินไม่ทำให้สำนักงาน omniscient และไม่ทำให้ combat แก้ anomaly ได้ทุกชนิด

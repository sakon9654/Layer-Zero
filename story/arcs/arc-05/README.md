## จุดตั้งต้น

- เหตุเกิดประมาณสามวันหลังคดีโกดังและการปรากฏของแหวน
- การประเมินภาคสนามแบบจำกัดของนนท์ยังถูกพักชั่วคราว เพราะสำนักงานยังไม่รู้ขอบเขตและความเสี่ยงของแหวน
- แหวนยังมีเพียง pattern เบื้องต้นจากการทดสอบจำกัด ห้ามสรุปว่าเป็นเครื่องตรวจเพศหรือผู้หญิง
- คดีหลักใหม่เกี่ยวข้องกับอาคารพักอาศัยและความผิดปกติของการมีอยู่/การถูกนับว่าเป็นผู้อยู่อาศัย
- คดีใหม่นี้ต้องยืนได้ด้วยตัวเอง และห้ามสรุปว่าเกิดจากแหวนหรือเชื่อมกับ Object ในโกดังเพียงเพราะเหตุการณ์เกิดใกล้กัน
- เป้าหมายพัฒนาการของนนท์คือพิสูจน์ว่าความเสี่ยงที่ติดตัวเขาสามารถบริหารด้วย protocol ได้ ไม่ใช่การเลื่อนเป็นเจ้าหน้าที่แบบข้ามขั้น

## หลัก continuity

- นนท์ยังไม่ใช่เจ้าหน้าที่สำนักงานและไม่มีอำนาจภาคสนาม
- ริน พิม เอก และอธิคมยังใช้บทบาทตามโครงสร้างเดิม
- แหวนต้องสร้างข้อจำกัดและข้อมูลใหม่ ไม่ใช่กลายเป็นเครื่องมือไขคดีอัตโนมัติ
- รักษา Known Rules / Suspected Rules แยกจากกัน
- ไม่รีบเชื่อมคดีนี้กับบัตร 24, 23.41, ผู้เปิดประตู, พ่อของนนท์, ชายเสื้อเทา หรือปมเก่าจาก ARC ก่อนหน้า
- อดีตรินอาจสะท้อนผ่านพฤติกรรมการทำงาน แต่ยังไม่เปิดเผยเหตุการณ์จริง
